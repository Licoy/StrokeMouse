macOS 向けのマウス／トラックパッドジェスチャカスタムツールです。マウスボタンを押したまま軌跡を描く、修飾キーを 1 つ押したままトラックパッド描画する、または実験的な複数指タッチジェスチャを使えます。一致するとショートカット、アプリを開く、ウインドウ操作、メディアキー、Shell / AppleScript などを実行します。**グローバルまたは特定 App** に適用でき、ジェスチャ設定は**読み込み／書き出し**可能、ローカル実行でメニューバーに常駐します。

## 機能

- **メニューバー常駐**: ジェスチャの開始／停止、設定を開く、終了。アイコンは状態（通常／一時停止／権限不足）で色が変わります。**メニューバーアイコンを隠す**こともできます（Dock も隠す場合は再確認。隠したあとは Dock をクリックするかアプリを再起動して設定を開きます）
- **ジェスチャライブラリ**: サイドバーを**グローバル／App ごと**に整理（新規作成時に範囲を事前入力）。検索／フィルタ／並べ替え。複数選択で一括の有効化・無効化・削除。**JSON の読み込み／書き出し**（重複はスキップまたは強制読み込み）
- **マウス描画**: ジェスチャごとに右ボタン、中ボタン、サイドボタンを独立して選べます。有効な設定が使うボタンだけを監視します
- **トラックパッド描画**: Fn / Control / Option / Shift / Command のいずれか 1 つ（デフォルトは Fn）を押したままポインタを動かして描きます。対応修飾キーを追加で押すと、その認識はキャンセルされます
- **実験的タッチジェスチャ**: 内蔵トラックパッドは 3〜5 本指のタップ／ダブルタップ／四方向スワイプと、2〜5 本指のピンチ／スプレッド／時計回り・反時計回りの回転など 34 種類をサポートします
- **タッチジェスチャのマスタースイッチ**: 設定済みジェスチャを削除せずにタッチジェスチャチャネルだけをオフにできます。非公開バックエンドの障害はタッチチャネルだけを低下させ、マウス描画とトラックパッド描画は維持されます
- **スクロール強化**: マウスホイールとトラックパッド / Magic Mouse の縦・横を別々に反転でき、ノッチ式ホイールはスムーズスクロール（やわらか / 標準 / 敏速、または速度・時間・加速のカスタム）も選べます。除外リストは最前面アプリ基準で、設定はこの Mac だけに残りバックアップ同期には入りません。他のスクロールツールと同時に動かすと二重処理になることがあり、整数行だけを読むアプリ（一部のゲーム、VM、リモートデスクトップ）は除外してください
- **ジェスチャごとのターゲット**: トリガーを押した瞬間の最前面アプリ、またはポインタ下のアプリを選べます。通常のウインドウがあればそのウインドウも固定し、アプリ範囲の判定とターゲット対応アクションは常にそのターゲットを再利用します
- **自由軌跡認識**: ジェスチャごとに1〜5個のサンプルを記録でき（3個推奨）、最も高いスコアのサンプルを採用。弧長リサンプリング、1D/2D正規化、制限付き回転、順序付き曲線シグネチャ、接線を考慮した曲線スコア、および明確な折れ曲がり構造ゲートを使用。一般設定でグローバル一致しきい値を調整でき、トリガーを押している間はリアルタイム軌跡HUDを表示します
- **App 範囲**: グローバル、またはインストール済みアプリからアイコンで追加（検索／`.app` を参照）
- **多彩なアクション**: ショートカット、アプリを開く／切り替え、URL、メディアキー、ウインドウ操作、Shell / AppleScript（シンタックスハイライト。AppleScript にはスリープ、画面ロック、ゴミ箱を空にするなどのプリセットとカスタム）
- **使い勝手**: 英語・簡体字中国語・繁体字中国語・韓国語・日本語・ロシア語・フランス語の UI（またはシステム言語に従う）、ライト／ダーク（システム／固定）、ログイン時に開く、Dock／メニューバーアイコンを隠す、Sparkle によるアプリ内アップデート（失敗時は GitHub Releases にフォールバック）

## システム要件

- macOS 14 Sonoma 以降
- Xcode 16+（開発ビルド）
- 描画ジェスチャはマウスまたはトラックパッドで実行できます。直接マルチタッチは主に Mac 内蔵トラックパッド向けです
- 外付け Magic Trackpad はベストエフォート対応で、機種や macOS のバージョンによって異なる場合があります

## インストール

### Homebrew（推奨）

StrokeMouse プロジェクトが管理する [Licoy Homebrew Tap](https://github.com/Licoy/homebrew-tap) からインストールします。

```bash
brew install --cask licoy/tap/strokemouse
```

StrokeMouse はアプリ内アップデートにも対応しています。Homebrew で強制的に確認してアップグレードするには:

```bash
brew upgrade --cask --greedy strokemouse
```

アンインストール時は設定が残ります。設定も消すには `--zap` を付けます。

```bash
brew uninstall --cask strokemouse
brew uninstall --cask --zap strokemouse
```

[公式ダウンロードページ](https://strokemouse.com/ja/download) からアーキテクチャに合った DMG を入手することもできます。現行リリースは固定の自己署名コード署名を使い、Apple の公証は受けていません。初回起動が Gatekeeper にブロックされたら、App を Control クリックして「開く」を選ぶか、「システム設定 → プライバシーとセキュリティ」で「このまま開く」を選んでください。

## 権限

| 権限 | 用途 |
|------|------|
| **アクセシビリティ** | グローバルなマウス／修飾キー／スクロール監視（`CGEventTap`）、ショートカット注入、ウインドウ AX 操作 |
| **自動化** | 任意。AppleScript が他の App を制御するときに必要 |

初回起動時、または **設定 → 権限** でアプリ内の**ガイド承認**を使えます。システム設定を開き、StrokeMouse をリストにドラッグしてスイッチをオンにします。信頼されていないときは、エンジンは監視しているふりをしません。

### 実験的タッチジェスチャ

タッチジェスチャは実行時の `dlopen` / `dlsym` で Apple 非公開の `MultitouchSupport` を読み込み、そのプライベートフレームワークを静的リンクしません。macOS の更新後に動かなくなることがあります。フレームワーク、シンボル、デバイスの欠落やデバイス起動の失敗はタッチチャネル障害として表示され、マウス描画とトラックパッド描画は続けて使えます。模擬フォールバックや黙った再試行はありません。

StrokeMouse はトラックパッドのネイティブイベントを横取りしないため、システムのジェスチャがバインドしたアクションと同時に起きることがあります。生のタッチ軌跡も保存・記録しません。有効なタッチジェスチャ設定を初めて保存、有効化、読み込むときに実験リスクの確認が表示されます。その後はマスタースイッチで設定を削除せずにタッチジェスチャを一時停止できます。

対応するタッチジェスチャ 34 種類:

| 種類 | 指数 | バリエーション | 数 |
|------|------|----------------|----|
| タップ | 3 / 4 / 5 本 | シングル、ダブル | 6 |
| スワイプ | 3 / 4 / 5 本 | 上、下、左、右 | 12 |
| 拡大縮小 | 2 / 3 / 4 / 5 本 | ピンチ、スプレッド | 8 |
| 回転 | 2 / 3 / 4 / 5 本 | 反時計回り、時計回り | 8 |
| **合計** |  |  | **34** |

初版は 2 本指タップ／スワイプ、修飾キーの組み合わせ、特定の指の識別、連続繰り返しアクション、ユーザー調整可能な認識しきい値には対応しません。

## ビルドと実行

### 依存関係

```bash
brew install xcodegen
```

### プロジェクトを生成して開く

```bash
./scripts/generate_project.sh
open StrokeMouse.xcodeproj
```

または Xcode で直接 **Run**（Scheme: `StrokeMouse`）。

### CLI ビルド（推奨）

リポジトリ下の `output/StrokeMouse.app` に固定出力し、アクセシビリティの再承認を減らします。  
Debug の表示名は **StrokeMouse Dev**（Bundle ID `com.strokemouse.app.dev`）で、製品版 **StrokeMouse** とアクセシビリティで別々に承認できます。

```bash
./scripts/build.sh           # Debug → output/StrokeMouse.app（アクセシビリティ: StrokeMouse Dev）
./scripts/build.sh --open    # ビルド後に自動で開く
./scripts/build.sh --release # Release（表示名 / Bundle ID は製品パッケージと同じ）
```

### リリースパッケージ

アーキテクチャごとに ZIP、TAR.GZ、DMG を作り、署名、entitlements、成果物の整合性を検証します（デフォルトは固定の自己署名 ID **`StrokeMouse Release`**。Sparkle 更新後もアクセシビリティ権限が残るようにします）。

```bash
# 初回ローカル: ./scripts/generate-codesign-cert.sh --import
SPARKLE_PUBLIC_KEY="..." ARCH=arm64 ./scripts/package-app.sh
SPARKLE_PUBLIC_KEY="..." ARCH=x86_64 ./scripts/package-app.sh
```

リリースと CI secrets は `RELEASING.md` / `certs/README.md` を参照してください。

バージョン公開は `./bump.sh -v x.y.z [-p]`。同じバージョンを再タグしてプッシュするには `./bump.sh -v x.y.z --force`。

### テスト

```bash
xcodebuild -scheme StrokeMouse -configuration Debug test
```

## 使い方

1. アプリを起動すると、メニューバーにマウスのアイコンが出ます  
2. **アクセシビリティ** を許可し、メニューバーからジェスチャを有効にします  
3. **設定 → ジェスチャ** でデフォルトを確認するか、新規作成します  
4. 入力を選びます。マウストリガーを押したまま描く、修飾キーを 1 つ押したままトラックパッド描画する、または設定済みのタッチジェスチャを行う
5. 一致すると、バインドしたアクションが実行されます  

> **短いクリックとジェスチャ**: トリガーの押下／解放はエンジンが一時的に取り込みます。「最小移動距離」に達する前に離すと通常クリックとして再生され、コンテキストメニューは使えます。描画が始まるとドラッグはシステムのカーソルと軌跡 HUD を動かしますが、最前面アプリは対になった押下／解放を受け取らないため、コンテキストメニューは開かれたり選択されたりしません。左クリックとトリガーに設定していないボタンは常に通過します。

> **トラックパッド描画**: 修飾キーの監視は listen-only で、キーボードイベントを消費しません。短いパスではアクションを実行しません。パスはシステムのポインタに従うため、トラックパッドでもマウスでも動かせます。StrokeMouse は修飾キー自体のアクティブ App への効果を抑えません。

> ショートカットはまず固定したアプリを前面にし、正確なウインドウが取れていればそのウインドウも前面に出すため、フォーカスやスペースが切り替わることがあります。Finder のデスクトップなど通常ウインドウがない場所でもショートカットと「App を隠す」は実行できます。閉じる、最小化、ズーム、フルスクリーン、中央揃えは正確なウインドウが必要です。短いクリックはターゲットを前面にしません。

デフォルトのジェスチャ例（デフォルトは右ボタン。ジェスチャごとに別のボタンを使えます）:

| ジェスチャ | アクション |
|------------|------------|
| ↑ | Mission Control（⌃↑） |
| ↓ | アプリケーションウインドウ（⌃↓） |
| ↓← | ウインドウを最小化 |
| ↓→ | ウインドウを閉じる |
| ↑→ | Safari を開く |
| →← | 再生／一時停止 |
| ↑← | GitHub を開く |

## 設定ファイル

パス:

```text
~/Library/Application Support/StrokeMouse/gestures.json
```

日常的には **設定 → ジェスチャ** で複数選択して JSON パッケージを書き出し／読み込みます。ライブラリ全体のバックアップは上記ファイルをコピーするか手編集します（構造は正当である必要があります）。設定から「Finder に表示」できます。

## 技術スタック

- Swift / SwiftUI（macOS 14+）
- 軽量 MVVM + Service
- グローバルなマウス／修飾キーイベント用 `CGEventTap`
- 実験的タッチジェスチャ向け `MultitouchSupport` の実行時 `dlopen` / `dlsym` 読み込み（静的リンクなし）
- JSON 設定の永続化
- ログイン時起動の [LaunchAtLogin-Modern](https://github.com/sindresorhus/LaunchAtLogin-Modern)
- 署名付きアプリ内アップデートの [Sparkle](https://github.com/sparkle-project/Sparkle)
- Xcode プロジェクト管理の XcodeGen
