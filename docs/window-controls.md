# 扩展窗口控制

在手势编辑器中选择「动作类型 → 窗口操作」。新增能力也可以用于鼠标绘制的第二动作。

- **自定义窗口大小及位置**：X、Y、宽度、高度均为当前屏幕可用区域的百分比，原点位于左上角，排除菜单栏和 Dock。示意图随输入实时变化，可快速选择左半屏、右半屏、居中 80%。窗口不得超出屏幕范围，无效输入会阻止保存。
- **恢复窗口前一个位置**：恢复通过本应用居中、最大化、自定义布局、单轴最大化或跨屏前的窗口位置和大小，可在前后两种布局间切换，重复最大化或居中不会覆盖之前的位置记录，连续触发最大化时也会保留首次调整前的布局。记录仅在本次运行中保留，最多保存 100 个窗口；不记录其他应用手动拖动的历史。
- **窗口高度／宽度最大化**：只改变对应轴的位置和尺寸，保留另一轴。
- **移动窗口到下一个屏幕**：按 macOS 显示器列表循环移动，按可用区域比例换算位置与大小，并限制到目标屏幕内；只有一个屏幕时明确提示。
- **恢复最小化窗口**：还原手势目标应用的一个最小化窗口并将其置前，不保证按最小化的时间排序。
- **最小化应用全部窗口／恢复应用全部最小化窗口**：仅作用于手势开始时锁定的应用。恢复全部会恢复该应用当前所有最小化窗口，包括本应用之外的操作最小化的窗口；不是只撤销最近一次批量操作。

窗口操作始终使用手势开始时冻结的目标，批量操作也只处理该目标应用。窗口尺寸受目标应用的最小／最大尺寸、固定比例、全屏状态等限制，自定义布局会先等待尺寸稳定，再定位；应用将尺寸限制到最小／最大尺寸但确实完成调整时视为成功，完全不响应缩放或未能应用位置时才报告失败，批量部分失败也会报告。

保存包含这些新增动作的配置和备份使用 v8，旧配置无需迁移；旧版 StrokeMouse 无法读取 v8，请保留旧版配置备份。
