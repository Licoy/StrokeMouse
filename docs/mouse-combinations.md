# 鼠标组合触发

在「设置 → 手势 → 新增 → 鼠标组合」中配置，无需录制轨迹。每条配置使用已有的动作选择器、目标窗口、全局 / 应用 / 应用组作用域，并可导入、导出和备份。

## 支持的操作

| 触发方式 | 可选操作 | 执行时机 |
| --- | --- | --- |
| 按住右键 | 滚轮向上、滚轮向下 | 每次有效滚轮事件，支持连续操作 |
| 按住右键 | 点击左键 | 本次右键按住期间首次点击左键 |
| 屏幕上 / 下 / 左 / 右边缘 | 点击右键 | 在同一所选边缘按下并松开右键，且未开始绘制 |
| 屏幕上 / 下 / 左 / 右边缘 | 滚轮向上、滚轮向下 | 有效滚轮事件，最多每 100 毫秒一次，无需按住右键 |

例如，可将「按住右键 + 向上滚动」设为切换到上一个标签页，将「按住右键 + 点击左键」设为关闭标签页，将「右边缘 + 滚轮」设为调节音量。动作默认留空，由使用者选择。

## 与现有操作的关系

- 按住右键后，滚轮 / 左键组合优先执行，随后松开右键不会再次识别绘制轨迹或弹出右键菜单。
- 仅按下再松开右键、未触发组合时，仍可正常打开右键菜单。
- 未配置的滚轮方向继续正常滚动，未配置组合的应用保留原输入。
- 同时存在「右键 + 左键」组合和绘制手势的左键第二动作时，组合优先；没有该组合时，原第二动作保持原有行为。
- 同一个触发操作优先采用应用配置，其次是应用组，最后是全局。同一级存在多个匹配时提示冲突，不执行动作。
- 组合受手势总开关、暂停、权限和录制 / 编辑时的输入抑制控制，可在应用策略中单独停用全局「鼠标组合」。

## 边缘与滚轮

- 边缘范围为每块显示器实际边界以内 3 个逻辑点，使用 Quartz 显示器坐标，支持主显示器上方、左侧的显示器；相邻显示器之间的接缝也视为边缘。
- 角落可能同时满足两条边缘配置，同一级匹配多个操作时按冲突处理。
- 支持普通滚轮及罗技等设备的原生高精度像素滚轮输入；触控板手势、系统惯性滚动，以及其他滚动工具补发的平滑帧不作为新的动作触发。
- 贴边滚轮每 100 毫秒最多执行一次动作，无论普通或高精度滚轮都适用；未配置的反向滚动不会执行该动作。
- 按住右键时，平滑滚轮的动作最短间隔为 120 毫秒，方向反转和重新按下右键可立即触发，避免单次滚动产生的大量平滑帧连续切换标签页。
- 向上 / 向下按照系统滚轮事件方向识别，识别先于应用内的滚动反向和平滑增强。
- 组合消费的滚轮不会继续滚动页面，未匹配应用作用域的边缘滚轮会带防重入标记回放，并正常经过滚动增强。

## 实现与验证

`GestureInput.mouseCombination` 保存组合配置；鼠标按键与按住右键时的组合沿用原会话和冻结目标。边缘滚轮不占用手势会话，先吞下刻度，在独立队列解析目标应用和窗口，回调只读取加锁状态，不执行 AX、NSWorkspace 或主线程同步调用。没有作用域匹配、或刻度送达时已不满足条件，都会按原增量新建滚轮事件回放，不沿用吞下时的光标位置。

鼠标和滚动增强的事件监听器通过同一滚轮入口协调，避免安装顺序影响组合优先级；不会监听任何连续鼠标移动事件。旧配置无需迁移，新组合使用独立的输入类型。

自动化回归覆盖：多显示器边缘坐标、配置往返、离散 / 连续 / 合成事件过滤、滚动增强优先关系、右键组合重复与互斥、普通右键回放、作用域优先级 / 冲突、应用排除和暂停。

手动体验时建议先设置无破坏性的快捷键或媒体动作，确认右键菜单、浏览器滚动、多显示器边缘和所选应用作用域。辅助功能需为开发版「StrokeMouse Dev」单独授权。
