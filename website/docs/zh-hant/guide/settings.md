# 設定與選單列

## 選單列

選單列圖示提供日常控制入口：

- **啟停手勢** — 暫時暫停 / 恢復引擎
- **暫停 / 恢復捲動增強** — 至少開啟一項捲動功能後出現，與手勢暫停互不影響
- **打開設定** — 進入設定視窗
- **狀態色** — 正常；**黃色**表示手勢已暫停；**紅色**表示缺少輔助使用權限
- **結束**

應用可設定為登入時啟動、隱藏 Dock 圖示、**隱藏選單列圖示**。隱藏選單列後，點擊 Dock 中的 StrokeMouse 或再次打開 App 會打開設定；若 Dock 也隱藏，透過再次啟動 App 進入設定。一般設定中可恢復選單列並**結束應用**。

同時隱藏 Dock 與選單列時會二次確認，避免失去所有可見入口。

## 設定視窗結構

| 分區 | 內容 |
|------|------|
| **手勢** | 側邊欄（全域 / 各 App）+ 列表：搜尋 / 篩選 / 多選批次操作、匯入匯出、編輯器 |
| **捲動** | 分軸反向、一般滾輪平滑、按前景應用程式排除；只存本機 |
| **一般** | 主題、登入時啟動、隱藏 Dock / 選單列、結束應用等 |
| **權限** | 輔助使用 / 自動化狀態、引導授權與系統設定 |
| **關於** | 版本與產品資訊 |

## 捲動增強 {#scroll-enhancement}

**設定 → 捲動** 提供與手勢分開的滾輪增強。系統「自然捲動」仍是滑鼠和觸控板共用的一個開關；這裡可以再按裝置、按軸向反一次，也可以讓一般滾輪帶上慣性。

- **總開關**預設開，反向和平滑預設關。一項功能都沒開時不會安裝捲動監聽，原有手勢不受影響
- **反向**把滑鼠滾輪、觸控板與巧控滑鼠分開，各自有縱向和橫向。它疊在系統「自然捲動」之上。反轉觸控板橫向可能影響瀏覽器的輕掃翻頁；按住 Shift 捲動產生的橫向移動跟隨縱向設定
- **平滑捲動**只處理一般滾輪，不處理觸控板，也不處理沒有手勢相位的高精度滾輪。預設為柔和、標準、靈敏；在「進階」裡拖動速度、時長或加速會變成自訂。速度和加速只在平滑開啟時生效。按住 Command、Option、Control 或 Shift 時保持系統原生捲動
- **排除的應用程式**看的是**前景應用程式**，不是指標下的視窗。適合遊戲、遠端桌面、虛擬機，以及只讀取整數行增量、平滑後會捲得偏少的應用程式
- 暫停手勢不會暫停捲動，設定視窗打開時也可以直接試捲。至少開啟一項後，選單列會出現「暫停捲動增強 / 恢復捲動增強」。選單列圖示仍只反映手勢狀態
- 這些設定只存在本機，不進入手勢匯出、`gestures.json` 或備份同步。和其他捲動工具同時運行時，事件可能被處理兩次

捲動監聽同樣需要輔助使用。未授權時捲動保持系統原生，**設定 → 權限** 會單獨顯示捲動狀態。

## 手勢列表

- 左側欄按 **全域** 與**已關聯 App** 分組瀏覽（類似系統設定中的快捷鍵範圍）；在某一 App 下**新增**會預填對應範圍
- 查看名稱、觸發鍵、動作、**範圍（全域或 App 圖示）**、啟用狀態
- **搜尋**名稱 / 動作 / 備註；按 **全部 / 已啟用 / 已停用** 篩選；表頭排序
- 新增 / 編輯 / 刪除；**多選**後批次啟用、停用、刪除或匯出
- **匯入 / 匯出** JSON 手勢包：匯出目前選中項；匯入時若內容重複，可略過或強制匯入（強制匯入的重複項預設關閉）
- 預設手勢可改可刪；也可隨時加回自己的範本

## 手勢編輯器

編輯單條 `GestureProfile` 時通常包括：

1. **名稱** 與備註
2. **觸發鍵**
3. **軌跡** — 錄製 free-path 點列，或基於方向範本
4. **動作** — 見 [動作類型](./actions)
5. **範圍** — 全域，或從已安裝應用程式中按圖示搜尋 / 多選 / 瀏覽 `.app` 新增（底層為 bundle id）
6. **啟用開關**

錄製時按住觸發鍵畫線，鬆手完成；可反覆錄製直到滿意。

## 主題與語言

- 介面主題：跟隨系統，或強制淺色 / 深色
- 文案：英語、簡體中文、繁體中文、韓語、日語、俄語、法語；也可跟隨系統語言

## 首次引導

首次啟動可能出現 onboarding 引導，提示授權與基本用法。可隨時在權限頁與文件中回顧。

## 備份與分享設定

- **日常**：設定 → 手勢 → 匯出選中項為 JSON；在另一台機器上匯入
- **整庫**：設定中可「在 Finder 中顯示」設定目錄，複製 `gestures.json`。詳見 [設定檔](./config-file)
