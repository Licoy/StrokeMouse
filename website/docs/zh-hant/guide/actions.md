# 動作類型

比對成功後，`ActionExecutor` 按設定分發動作。以下為目前支援的類型。

## 一覽

| 類型 | 說明 | 注意 |
|------|------|------|
| 無動作 | 僅用於測試比對 | — |
| **快捷鍵** | 注入系統快捷鍵（含修飾鍵） | 依賴輔助使用 |
| **開啟 App** | 從已安裝應用程式中按圖示選擇並啟動 | 底層按 bundle id |
| **開啟 URL** | 用預設瀏覽器打開連結 | — |
| **媒體鍵** | 播放暫停、上下曲、音量、靜音 | — |
| **視窗操作** | 關閉、最小化、縮放、全螢幕、隱藏、置中 | 依賴 AX |
| **Shell** | 執行 shell 命令（編輯器語法醒目提示） | **高權限** |
| **AppleScript** | 內建預設或自訂指令碼（編輯器語法醒目提示） | **高權限**，可能需自動化權限 |

## 快捷鍵

快捷鍵只能透過錄製設定，顯示欄位不可直接編輯。點擊「錄製」後，按實際順序按下組合鍵，放開全部按鍵後完成；單獨按 Esc 可取消錄製。

支援包含普通鍵的組合（如 `⌘⌥Q`），也支援純修飾鍵組合（如 `⌘⌥`）。錄製結果按實際按下順序顯示；修飾鍵僅支援 Command、Option、Control 和 Shift。

錄製快捷鍵後可點擊「新增後續按鍵」，再錄製最多 3 組按鍵；執行時在同一目標中依序按下，組間間隔約 50 毫秒，任一步失敗即停止。例如 `⌘V` 後接 `↩` 可在聊天軟體中貼上並送出。舊版本只會執行第一組快捷鍵。

典型用途：Mission Control、切換桌面、App 內快捷鍵等。

## 開啟應用程式

在動作選擇器中從**已安裝應用程式**按圖示搜尋、瀏覽 `.app` 選擇即可，無需手寫 bundle id（底層仍按 bundle identifier 啟動）。名稱用於列表展示。

## 開啟 URL

任意 `https://` / `http://` 等系統可處理的 URL。預設手勢中的「打開 GitHub」即此類型。

## 媒體鍵

| 命令 | 作用 |
|------|------|
| playPause | 播放 / 暫停 |
| nextTrack / previousTrack | 下一曲 / 上一曲 |
| volumeUp / volumeDown / mute | 音量與靜音 |

## 視窗操作

| 命令 | 作用 |
|------|------|
| close | 關閉視窗 |
| minimize | 最小化 |
| zoom | 縮放（綠鍵語意） |
| fullscreen | 全螢幕 |
| hide | 隱藏應用程式 |
| center | 視窗置中 |

目標通常為目前前景視窗；若 AX 不可用可能失敗，請確認輔助使用已授權。

## Shell

執行本機 shell 命令字串。編輯器提供語法醒目提示，便於核對長命令。

::: danger 風險
Shell 擁有與目前使用者相當的檔案系統與行程權限。惡意或誤寫命令可造成資料損失。請只貼上你理解且信任的命令。
:::

## AppleScript

可選用**內建預設**（如睡眠、清空廢紙簍、鎖定螢幕、螢幕保護程式、登出 / 重新啟動 / 關機、切換深色模式、隱藏其他視窗、靜音 / 取消靜音、強制結束面板、截圖到剪貼板、打開下載檔案夾），或切換為**自訂**指令碼。控制其他 App 時，系統可能要求 **自動化** 權限。編輯器同樣支援語法醒目提示。

::: danger 風險
與 Shell 類似，具有自動化與指令碼執行能力。勿執行來源不明的指令碼。
:::

## 選擇建議

| 目標 | 建議動作 |
|------|----------|
| 系統 / App 快捷鍵 | 快捷鍵 |
| 啟動某軟體 | 開啟 App |
| 網頁書籤式跳轉 | 開啟 URL |
| 音樂與音量 | 媒體鍵 |
| 視窗管理 | 視窗操作 |
| 高度自訂 | Shell / AppleScript（慎用） |

設定持久化見 [設定檔](./config-file)。
