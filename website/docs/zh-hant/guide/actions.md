# 動作類型

比對成功後，`ActionExecutor` 按設定分發動作。以下為目前支援的類型。

## 一覽

| 類型 | 說明 | 注意 |
|------|------|------|
| 無動作 | 僅用於測試比對 | — |
| **快捷鍵** | 注入系統快捷鍵（含修飾鍵） | 依賴輔助使用 |
| **系統** | 指揮中心、應用程式視窗、上一個 / 下一個空間 | 依賴輔助使用；需與系統快速鍵一致 |
| **開啟 App** | 從已安裝應用程式中按圖示選擇並啟動 | 底層按 bundle id |
| **開啟 URL** | 用預設瀏覽器打開連結 | — |
| **媒體鍵** | 播放暫停、上下曲、音量、靜音 | — |
| **視窗操作** | 關閉、最小化、縮放、最大化、全螢幕、隱藏、置中 | 依賴 AX |
| **Shell** | 執行 shell 命令（編輯器語法醒目提示） | **高權限** |
| **AppleScript** | 內建預設或自訂指令碼（編輯器語法醒目提示） | **高權限**，可能需自動化權限 |

## 快捷鍵

快捷鍵只能透過錄製設定，顯示欄位不可直接編輯。點擊「錄製」後，按實際順序按下組合鍵，放開全部按鍵後完成；單獨按 Esc 可取消錄製。

支援包含普通鍵的組合（如 `⌘⌥Q`），也支援純修飾鍵組合（如 `⌘⌥`）。錄製結果按實際按下順序顯示；修飾鍵支援 Command、Option、Control、Shift 和 Fn/地球儀，Fn 可單獨使用，也可與其他按鍵組合，例如 macOS 15 及以上用於左右排列視窗的 `fn⌃⇧←`。

開始錄製前請先鬆開所有修飾鍵，再依希望回放的順序依序按鍵。Fn 需實際按下，在系統設定中改為 Fn 的按鍵（如大寫鎖定鍵）也可以；放開大寫鎖定鍵後，大寫鎖定可能仍維持開啟。

錄製快捷鍵後可點擊「新增後續按鍵」，再錄製最多 3 組按鍵；執行時在同一目標中依序按下，組間間隔約 50 毫秒，任一步失敗即停止。例如 `⌘V` 後接 `↩` 可在聊天軟體中貼上並送出。舊版本只會執行第一組快捷鍵。

典型用途：App 內快捷鍵等；指揮中心、應用程式視窗和切換空間建議使用下方的 [系統](#系統) 動作。

## 系統

在動作類型中選擇「系統」，可執行以下命令：

| 命令 | 預設快速鍵 | 目標 |
|------|-----------|------|
| 指揮中心 | ⌃↑ | 作用於目前桌面，不啟動鎖定的視窗 |
| 應用程式視窗 | ⌃↓ | 先啟動鎖定的應用程式 / 視窗 |
| 上一個空間 | ⌃← | 作用於目前桌面，不啟動鎖定的視窗 |
| 下一個空間 | ⌃→ | 作用於目前桌面，不啟動鎖定的視窗 |

系統動作透過送出「系統設定 › 鍵盤 › 鍵盤快速鍵 › 指揮中心」中對應的快速鍵執行，預設值與 macOS 預設設定一致。若你在系統中改過這些快速鍵，可在編輯器中錄製其他快速鍵覆寫，也可點擊「回復預設快速鍵」還原。編輯器會讀取上述系統設定，對應的系統快速鍵已關閉或與此處不一致時會顯示提示，並可點擊「改用系統快速鍵」直接採用系統中的設定。StrokeMouse 不會修改系統設定。

使用預設快速鍵但該快速鍵在系統設定中已關閉時，執行會顯示錯誤提示，而不是靜默無效。

這些是離散命令，每次觸發執行一次，不提供原生四指手勢那樣跟隨手指的連續動畫。觸控手勢的四指上滑 / 下滑預設使用的就是指揮中心和應用程式視窗這兩個系統動作。

含系統動作或拖曳捲動的設定與匯出使用 **v4** 格式，僅含 Fn 快捷鍵時使用 **v3**，其他設定仍為 **v2**；舊版本無法讀取 v3 / v4 檔案。

## 開啟應用程式

在動作選擇器中從**已安裝應用程式**按圖示搜尋、瀏覽 `.app` 選擇即可，無需手寫 bundle id（底層仍按 bundle identifier 啟動）。名稱用於列表展示。

## 開啟 URL

任意 `https://` / `http://` 等系統可處理的 URL。預設手勢中的「打開 GitHub」即此類型。

## 媒體鍵

| 命令 | 作用 |
|------|------|
| playPause | 播放 / 暫停 |
| nextTrack / previousTrack | 下一曲 / 上一曲 |
| volumeUp / volumeDown / mute | 音量與靜音 |

## 視窗操作

| 命令 | 作用 |
|------|------|
| close | 關閉視窗 |
| minimize | 最小化 |
| zoom | 縮放至應用程式自訂尺寸 |
| maximize | 最大化視窗 |
| fullscreen | 全螢幕 |
| hide | 隱藏應用程式 |
| center | 視窗置中 |

視窗動作使用手勢開始時鎖定的精確視窗，不會改為操作執行時的前景視窗；隱藏應用程式使用鎖定的應用程式，目標視窗缺失、不支援操作或未獲得輔助使用權限時會顯示失敗提示

**最大化視窗**填滿該視窗所在螢幕的可用區域，避開選單列和 Dock；再次觸發保持最大化，不還原之前的大小，`zoom` 使用應用程式自訂尺寸，`fullscreen` 進入全螢幕，而最大化仍留在目前桌面；此版本不會先退出全螢幕再最大化，請先手動退出全螢幕，視窗不支援調整位置或大小，或未達到所需位置和大小（例如可能受應用程式限制）時，會顯示失敗提示

主動作或第二動作包含最大化視窗的設定與匯出使用 **v5**，需要支援該格式的版本；不含此動作的設定沿用現有 v2/v3/v4 規則

## Shell

執行本機 shell 命令字串。編輯器提供語法醒目提示，便於核對長命令。

::: danger 風險
Shell 擁有與目前使用者相當的檔案系統與行程權限。惡意或誤寫命令可造成資料損失。請只貼上你理解且信任的命令。
:::

## AppleScript

可選用**內建預設**（如睡眠、清空廢紙簍、鎖定螢幕、螢幕保護程式、登出 / 重新啟動 / 關機、切換深色模式、隱藏其他視窗、靜音 / 取消靜音、強制結束面板、截圖到剪貼板、打開下載檔案夾），或切換為**自訂**指令碼。控制其他 App 時，系統可能要求 **自動化** 權限。編輯器同樣支援語法醒目提示。

::: danger 風險
與 Shell 類似，具有自動化與指令碼執行能力。勿執行來源不明的指令碼。
:::

## 選擇建議

| 目標 | 建議動作 |
|------|----------|
| 系統 / App 快捷鍵 | 快捷鍵 |
| 指揮中心、切換空間 | 系統 |
| 啟動某軟體 | 開啟 App |
| 網頁書籤式跳轉 | 開啟 URL |
| 音樂與音量 | 媒體鍵 |
| 視窗管理 | 視窗操作 |
| 高度自訂 | Shell / AppleScript（慎用） |

設定持久化見 [設定檔](./config-file)。
