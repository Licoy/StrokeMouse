# 設定檔

手勢與相關偏好以 **JSON** 持久化。日常建議用介面**匯入 / 匯出**部分手勢；整庫備份可直接複製本機檔案。

## 介面匯入 / 匯出

**設定 → 手勢**：

1. **匯出**：多選手勢 → 匯出為 JSON 包（格式與設定版本欄位一致）
2. **匯入**：選擇 JSON 檔案；若與現有手勢內容重複，可**略過重複**或**強制匯入**（強制匯入的重複項預設關閉）

適合分享幾條常用手勢、在多台機器間同步子集，而無需覆蓋整個設定庫。

## 整庫路徑

```text
~/Library/Application Support/StrokeMouse/gestures.json
```

設定介面可「在 Finder 中顯示」該目錄。

## 使用建議

| 場景 | 做法 |
|------|------|
| 分享 / 同步部分手勢 | **設定 → 手勢 → 匯出 / 匯入** |
| 整庫備份 | 複製整個 `StrokeMouse` 目錄或單獨複製 `gestures.json` |
| 捲動增強 | 只存在本機，不在 `gestures.json` 或備份同步裡；換機後到 **設定 → 捲動** 重設 |
| 換機 | 裝好 App 並授權後：匯入 JSON 包，或覆蓋同名 `gestures.json` 再啟動 |
| 手工編輯 | 保持合法 JSON；未知欄位應盡量向後相容（缺省值 / 可選） |
| 損壞復原 | 可刪掉檔案讓應用重新產生預設設定（會遺失自訂） |

::: warning
應用執行時可能寫回設定。請在結束 App 或確認無並行寫入時再覆蓋整庫檔案。
:::

## 設定裡大致有什麼

每條手勢（profile）通常包含：

- 唯一 id、名稱、是否啟用
- **觸發鍵**（右 / 中 / 側鍵等）
- **軌跡**（自由路徑點列；舊版方向序列仍可解碼並轉換）
- **動作**（快捷鍵、App、URL、媒體、視窗、Shell、AppleScript 等）
- **範圍**（全域或 bundle id 列表）
- 備註

具體欄位以應用版本的 `Codable` 模型為準；升級後舊檔案應盡量可讀。匯入時會遷移舊版方向序列為 free-path。

## 與 UI 的關係

日常請優先用 **設定 → 手勢** 編輯與匯入匯出。整庫 JSON 適合：

- 完整備份與換機還原
- 在版本庫中保存個人設定（注意勿提交含隱私的指令碼）
- 排查損壞的設定

## 隱私

Shell / AppleScript 內容可能含路徑或權杖。分享匯出包或設定檔前請自行去識別。
