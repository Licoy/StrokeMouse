# 手勢系統

理解觸發鍵、軌跡取樣與比對規則，才能穩定自訂手勢。捲動反向與平滑不在手勢庫裡，見 [設定與選單列](./settings#scroll-enhancement)。

## 核心流程

```text
按住觸發鍵 → 取樣路徑 → 位移 ≥ 最小滑動距離
       → 放開 → 在「同觸發鍵」的候選中比對 → 執行動作
```

1. **觸發鍵寫在每條手勢設定上**（預設右鍵）
2. 引擎只監聽**已啟用手勢**用到的按鍵集合
3. 放開時結合 **App 範圍** 與前景 `bundleIdentifier` 過濾候選

## 觸發鍵

每條手勢可獨立選擇：

| 觸發鍵 | 說明 |
|--------|------|
| 右鍵 | 預設；短按仍可出右鍵選單 |
| 中鍵 | 滾輪按下 |
| 側鍵後退 / 前進 | 常見滑鼠側鍵 |

未監控的按鈕**始終放行**，不會被手勢引擎劫持；左鍵預設同樣放行，例外見下方 [第二動作](#第二動作)。

## 第二動作

滑鼠繪製手勢可在編輯器中開啟 **第二動作**：按住觸發鍵繪製時點擊一次左鍵，放開後只執行第二動作，未點擊左鍵時執行主動作。

- 只有目標應用可用的手勢中存在第二動作時，按住觸發鍵期間的左鍵按下與放開才會被成對吞掉，其餘情況左鍵照常放行
- 辨識仍在全部候選中進行，左鍵只決定執行哪個動作；相符的手勢未設定第二動作時不執行任何動作並提示
- 點擊左鍵但未畫出有效軌跡時取消本次手勢，不回放右鍵點擊
- 觸控板繪製與觸控手勢不支援第二動作，始終執行主動作

## 滑鼠按鍵對應

在 **新增 → 滑鼠按鍵** 中為側鍵（後退 / 前進）或中鍵新增對應，按一下該按鍵即執行動作，無需繪製。選單內建「後退側鍵 · 後退」（⌘[）與「前進側鍵 · 前進」（⌘]）兩個預設。

- 放開按鍵時執行；同一按鍵也用於滑鼠繪製時，未達到 `minStrokeDistance` 按點擊執行對應，超過則辨識為繪製，一次按下不會同時觸發兩者
- 目標應用只有該按鍵的對應、沒有繪製手勢時，按住移動也按點擊處理
- 可開啟「需同時按住修飾鍵」並選擇 Fn / Control / Option / Shift / Command 之一，僅精確按住該鍵時觸發（如 ⌘ + 側鍵後退）；未開啟的對應在按住任何修飾鍵時都不觸發，因此同一按鍵可同時設定無修飾鍵與帶修飾鍵的對應；所選修飾鍵也用於觸控板繪製時會先進入觸控板繪製，對應不會觸發
- 沿用全域 / 應用組 / 指定應用範圍，只取最具體的一層；同一層有多條對應視為衝突，不執行並提示
- 目標應用沒有該按鍵的任何手勢或對應時，按鍵原樣放行，例如保留瀏覽器原生的後退 / 前進
- 右鍵不支援對應，以免吞掉右鍵選單；對應執行成功時不彈出比對提示

## 滑鼠組合

在 **新增 → 滑鼠組合** 中建立，無需錄製軌跡，可沿用全部動作、目標視窗與範圍。

| 觸發方式 | 滑鼠動作 | 執行時機 |
|--------|------|------|
| 按住右鍵 | 向上 / 向下捲動 | 每格滾輪執行一次，可連續觸發 |
| 按住右鍵 | 點擊左鍵 | 每次按住右鍵只在第一次點擊左鍵時執行 |
| 螢幕邊緣（上 / 下 / 左 / 右） | 點擊右鍵 | 在所選邊緣按下並放開右鍵，且未開始繪製 |
| 螢幕邊緣（上 / 下 / 左 / 右） | 向上 / 向下捲動 | 無需按住右鍵，最多每 100 毫秒執行一次 |

- 觸發組合的右鍵按住或點擊不會彈出右鍵選單，也不再辨識繪製；未觸發組合時右鍵照常可用
- 「按住右鍵 + 點擊左鍵」優先於第二動作；沒有該組合時第二動作維持原有行為
- 未設定的滾輪方向與沒有組合的應用照常捲動；組合使用的滾輪不會繼續捲動頁面
- 按住右鍵時，高精度滾輪的動作最短間隔 120 毫秒，避免一次捲動連續切換多個分頁；觸控式軌跡板、慣性捲動與其他捲動工具補發的平滑影格不會觸發動作
- 邊緣為每台顯示器邊界以內 3 個點，相鄰顯示器的接縫也算邊緣；角落同時命中兩條同級設定時視為衝突
- 範圍與衝突規則同滑鼠按鍵對應：只取最具體的一層，同一層有多條視為衝突，不執行並提示；應用策略可單獨停用全域「滑鼠組合」

## 短按回放

觸發鍵的 down 由引擎接管後：

- 若拖動距離 **未達到** `minStrokeDistance`：用帶標記的合成 down/up **回放**為普通點按，保證右鍵選單等行為可用；目標應用有該按鍵的對應時改為執行對應
- 若已開始有效繪製：該組 down/drag/up **只用於手勢**，不會同時交給前景 App

## 軌跡比對（freePath）

目前主路徑為**自由軌跡範本比對**：

- 有序弧長重採樣
- 1D / 2D 正規化
- **±12°** 有限旋轉搜尋
- 分數需 ≥ 設定閾值
- **顯著段數 / 連續轉角** 作為結構門檻（不可被分數補償）
- **不使用**鏡像、逆序或 near-miss 兜底

錄製時盡量畫乾淨、速度適中；複雜花體可多錄幾次選最穩的一條。

## 即時 HUD

按住觸發鍵拖動時，螢幕上會繪製目前軌跡，便於對齊範本方向與形狀。

## App 範圍

| 範圍 | 行為 |
|--------|------|
| 全域 | 任意前景 App 都可比對 |
| 指定 App | 僅當目前前景應用落在列表內時參與比對 |

在編輯器中可從**已安裝應用程式**按圖示搜尋、多選或瀏覽 `.app` 新增，無需手寫 bundle id（底層仍按 bundle identifier 過濾）。適合「僅在瀏覽器裡有效」或「僅開發工具裡有效」的手勢。

手勢列表的範圍欄會顯示「全域」或已選 App 的圖示摘要。**設定 → 手勢** 左側欄可按全域 / 各 App 瀏覽與管理；在某一節點下新增會預填對應範圍。

## 啟用 / 停用

每條手勢可單獨開關。停用後不參與監聽集合與比對，無需刪除設定。
