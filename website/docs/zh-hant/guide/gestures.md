# 手勢系統

理解觸發鍵、軌跡取樣與比對規則，才能穩定自訂手勢。捲動反向與平滑不在手勢庫裡，見 [設定與選單列](./settings#scroll-enhancement)。

## 核心流程

```text
按住觸發鍵 → 取樣路徑 → 位移 ≥ 最小滑動距離
       → 放開 → 在「同觸發鍵」的候選中比對 → 執行動作
```

1. **觸發鍵寫在每條手勢設定上**（預設右鍵）
2. 引擎只監聽**已啟用手勢**用到的按鍵集合
3. 放開時結合 **App 範圍** 與前景 `bundleIdentifier` 過濾候選

## 觸發鍵

每條手勢可獨立選擇：

| 觸發鍵 | 說明 |
|--------|------|
| 右鍵 | 預設；短按仍可出右鍵選單 |
| 中鍵 | 滾輪按下 |
| 側鍵後退 / 前進 | 常見滑鼠側鍵 |

左鍵與未監控的按鈕**始終放行**，不會被手勢引擎劫持。

## 短按回放

觸發鍵的 down 由引擎接管後：

- 若拖動距離 **未達到** `minStrokeDistance`：用帶標記的合成 down/up **回放**為普通點按，保證右鍵選單等行為可用
- 若已開始有效繪製：該組 down/drag/up **只用於手勢**，不會同時交給前景 App

## 軌跡比對（freePath）

目前主路徑為**自由軌跡範本比對**：

- 有序弧長重採樣
- 1D / 2D 正規化
- **±12°** 有限旋轉搜尋
- 分數需 ≥ 設定閾值
- **顯著段數 / 連續轉角** 作為結構門檻（不可被分數補償）
- **不使用**鏡像、逆序或 near-miss 兜底

錄製時盡量畫乾淨、速度適中；複雜花體可多錄幾次選最穩的一條。

## 即時 HUD

按住觸發鍵拖動時，螢幕上會繪製目前軌跡，便於對齊範本方向與形狀。

## App 範圍

| 範圍 | 行為 |
|--------|------|
| 全域 | 任意前景 App 都可比對 |
| 指定 App | 僅當目前前景應用落在列表內時參與比對 |

在編輯器中可從**已安裝應用程式**按圖示搜尋、多選或瀏覽 `.app` 新增，無需手寫 bundle id（底層仍按 bundle identifier 過濾）。適合「僅在瀏覽器裡有效」或「僅開發工具裡有效」的手勢。

手勢列表的範圍欄會顯示「全域」或已選 App 的圖示摘要。**設定 → 手勢** 左側欄可按全域 / 各 App 瀏覽與管理；在某一節點下新增會預填對應範圍。

## 啟用 / 停用

每條手勢可單獨開關。停用後不參與監聽集合與比對，無需刪除設定。
