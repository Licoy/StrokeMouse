# 權限說明

StrokeMouse 需要全域滑鼠監聽與（可選）自動化能力。權限失敗會在**選單列狀態**和**設定 → 權限**中可見，而不是靜默無效。

## 權限一覽

| 權限 | 是否必須 | 用途 |
|------|----------|------|
| **輔助使用（Accessibility）** | **必須** | 全域滑鼠與捲動事件（`CGEventTap`）、快捷鍵注入、視窗 AX 操作 |
| **自動化（Automation）** | 可選 | 使用 AppleScript 控制其他 App 時按需授權 |

## 輔助使用

### 為什麼需要

手勢引擎在系統級攔截**已設定觸發鍵**的滑鼠序列。沒有輔助使用信任時，`AXIsProcessTrusted()` 為否，應用**不得**假裝正在監聽。捲動增強在打開反向或平滑後，用同一項權限安裝只含滾輪事件的監聽；未授權時捲動保持系統原生。

### 如何開啟

建議使用應用內 **「引導授權」**（首次 onboarding 與設定 → 權限均可）：

1. 點擊 **引導授權** — 自動打開系統設定 **隱私權與安全性 → 輔助使用**，並顯示跟隨系統設定視窗的懸浮面板
2. 從懸浮面板把 **StrokeMouse**（Debug 建置為 **StrokeMouse Dev**）拖入授權列表
3. 打開開關；應用會在數秒內自動偵測到授權並啟動手勢引擎

也可手動進入系統設定完成同樣步驟。

### 常見情況

- **正式版線上更新**（固定 `StrokeMouse Release` 自簽）：通常**不必**重新授權輔助使用
- **從舊 ad-hoc 包升級到自簽包 / 更換簽署憑證 / 換路徑建置**：系統會要求**重新授權一次**
- **開關已開但無效**：關掉再開，或移除項目後重新加入並重啟 App
- **多份 App 副本**：只對你實際啟動的那一份授權

## 自動化

僅在動作類型為 **AppleScript** 且指令碼要控制其他應用程式時需要。系統會在首次相關呼叫時跳出授權對話框，按 App 粒度確認即可。

## 安全原則

- 全域事件監聽屬於高權限能力，請從可信管道取得建置產物
- **Shell / AppleScript** 可執行任意本機命令，UI 中會保留風險提示；**只新增你信任的指令碼**
- 日誌中不會把使用者指令碼全文打到公開管道（工程約定）

## 自檢清單

若手勢完全無反應：

1. 選單列是否顯示權限 / 引擎異常？
2. 系統輔助使用是否已勾選目前這份 App？
3. 手勢是否被暫停？
4. 是否在用**未設定**為觸發鍵的滑鼠按鈕？
