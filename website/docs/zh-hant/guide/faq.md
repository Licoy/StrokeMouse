# 常見問題 FAQ

## 手勢完全沒反應？

按順序檢查：

1. **輔助使用**是否已授權**目前這份** App（換路徑、換簽署憑證、或從 ad-hoc 遷到自簽包後要重授；同一正式簽署的線上更新通常不用）
2. 選單列是否顯示引擎暫停或權限錯誤
3. 對應手勢是否 **啟用**
4. 是否按住了該手勢設定的 **觸發鍵**（預設右鍵，不是左鍵）
5. 滑動是否過短（短按會回放為普通點按，不觸發動作）

詳見 [權限說明](./permissions) 與 [快速開始](./getting-started)。

## 右鍵選單沒了？

短按右鍵（幾乎不拖動）應仍跳出選單。若整段拖動已超過最小距離，事件會用於手勢而**不會**同時出選單——這是預期行為。

把「需要選單」的操作改成輕點，把「需要手勢」的操作畫夠長度即可。也可把手勢改到**中鍵 / 側鍵**，把右鍵完全留給系統選單。

## 總是誤觸發或比對錯手勢？

- 為易混軌跡增加差異（方向、轉折）
- 刪除不用的候選，減少同觸發鍵下的競爭
- 重新錄製更乾淨的範本
- 用 App 範圍限制只在某些軟體生效

## 比對太嚴 / 太鬆？

辨識含分數閾值與結構門檻。過嚴：放慢重錄、軌跡更接近範本；過鬆：改範本形狀、減少相似手勢。

## 視窗動作不生效？

確認輔助使用已開；部分 App 對 Accessibility 支援不佳。可改用等價快捷鍵動作。

## Shell / AppleScript 沒跑起來？

- 命令 / 指令碼本身是否在「終端機 / 指令碼編輯器」可獨立執行
- AppleScript 控制其他 App 時是否授予了**自動化**
- 查看是否有系統彈窗被擋住

## 隱藏了選單列圖示怎麼辦？

點擊 Dock 中的 StrokeMouse（若未隱藏 Dock），或再次打開 / 啟動 App，會打開設定視窗。在 **設定 → 一般** 可恢復選單列圖示，也可結束應用。若 Dock 與選單列都已隱藏，只能透過再次啟動 App 進入設定。

## 登入後沒有自動啟動？

在 **設定 → 一般** 打開登入時啟動。若系統設定裡被關過「登入項目」，需兩邊都打開。

## 深色 / 淺色不對？

一般設定中可強制主題，或改回「跟隨系統」。

## 設定丟了？

檢查 `~/Library/Application Support/StrokeMouse/gestures.json` 是否被刪或覆蓋。有備份則結束 App 後還原；若只有匯出的 JSON 包，用 **設定 → 手勢 → 匯入** 復原。見 [設定檔](./config-file)。

## 需要什麼滑鼠？

任意帶可設定觸發鍵的滑鼠即可。預設使用**右鍵**；可在手勢編輯中改為中鍵或側鍵。觸控式軌跡板點按通常可作為滑鼠鍵使用，完整多指手勢不是本產品的主要使用方式。捲動增強不要求特定滑鼠，一般滾輪才能平滑。

## 捲動方向或手感不對？

- 反向疊在系統「自然捲動」之上。滑鼠滾輪和觸控板（含巧控滑鼠）分開設定
- 平滑只作用於一般滾輪。觸控板和高精度滾輪只反向、不平滑
- 按住 Command、Option、Control 或 Shift 時不做平滑
- 前景應用程式在排除清單裡時不做任何處理。排除看的是前景應用程式，不是指標下面的視窗
- 和其他捲動工具一起開時可能被處理兩次
- 捲動設定不隨手勢備份走，換機要在 **設定 → 捲動** 重設

詳見 [設定與選單列](./settings#scroll-enhancement)。

## 如何備份 / 分享手勢？

- **部分手勢**：設定 → 手勢 → 多選 → **匯出** JSON；另一台機器 **匯入** 即可（重複內容可略過或強制匯入）
- **整庫**：複製 `~/Library/Application Support/StrokeMouse/` 或僅 `gestures.json`；換機裝好 App 並授權後還原檔案

詳見 [設定檔](./config-file) 與 [設定與選單列](./settings)。
