# 快速開始

用最少步驟讓 StrokeMouse 跑起來，並驗證第一筆手勢。

## 你需要什麼

- **macOS 14 Sonoma** 或更高
- 任意滑鼠（預設用手勢的**右鍵**觸發；可在編輯裡改成中鍵等）
- 願意授予 **輔助使用（Accessibility）** 權限

## 五步上手

### 1. 啟動應用程式

啟動後選單列會出現 StrokeMouse 圖示。應用以選單列常駐為主，可在設定中選擇是否隱藏 Dock 圖示。

### 2. 授予輔助使用權限

打開 **設定 → 權限**，依提示打開系統「隱私權與安全性 → 輔助使用」，勾選 StrokeMouse。

::: tip
未授權時引擎**不會**假裝在監聽。選單列與權限頁會給出可觀察狀態，而不是靜默失敗。
:::

### 3. 確認手勢已啟用

在選單列中確認手勢處於啟用 /「恢復手勢」狀態。若曾暫停，先恢復再試。

### 4. 打開預設手勢列表

**設定 → 手勢** 可查看開箱自帶的預設手勢（例如上滑 → Mission Control）。也可新增自己的軌跡與動作。

### 5. 畫第一筆

1. 按住該手勢的 **觸發鍵**（預設**右鍵**）
2. 在螢幕上拖出軌跡（例如向上滑）
3. 放開

比對成功後會執行綁定動作。按住觸發鍵時，螢幕上會有**即時軌跡 HUD** 回饋。

## 短按 vs 手勢

| 行為 | 結果 |
|------|------|
| 按下觸發鍵後**幾乎不移動**就放開 | 視為短按：回放為正常點按，**右鍵選單仍可用** |
| 位移超過「最小滑動距離」後放開 | 進入手勢辨識：整組 down/drag/up 用於手勢，**不會**同時跳出右鍵選單 |

左鍵和未設定為觸發鍵的滑鼠按鈕始終放行，不受影響。
