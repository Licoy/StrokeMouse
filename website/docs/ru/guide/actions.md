# Действия

При успешном совпадении `ActionExecutor` отправляет настроенное действие.

## Обзор

| Тип | Что делает | Заметки |
|------|----------------|-------|
| Нет | Только совпадение / тест | — |
| **Сочетание** | Вставить аккорд клавиш | Нужен Универсальный доступ |
| **Открыть приложение** | Выбрать установленное приложение по значку и запустить | Хранится как bundle id |
| **Открыть URL** | Браузер / обработчик по умолчанию | — |
| **Медиа** | Воспроизведение/пауза, треки, громкость, без звука | — |
| **Окно** | Закрыть, свернуть, масштаб, развернуть, полный экран, скрыть, по центру | Нужен AX |
| **Shell** | Выполнить команду оболочки (редактор с подсветкой) | **Высокие права** |
| **AppleScript** | Встроенные пресеты или свой скрипт (с подсветкой) | **Высокие права**; может понадобиться Автоматизация |

## Сочетание

Сочетания настраиваются только записью; поле отображения только для чтения. Нажмите **Запись**, нажмите клавиши в нужном порядке, отпустите все, чтобы закончить. Один Esc отменяет.

Поддерживаются сочетания с обычной клавишей (например, `⌘⌥Q`) и только из модификаторов (например, `⌘⌥`). Результат показывается в порядке нажатия. Поддерживаемые модификаторы: Command, Option, Control и Shift.

## Открыть приложение

В выборе действия возьмите **установленные приложения** по значку (поиск или обзор `.app`) — bundle id вручную вводить не нужно (запуск всё равно использует идентификатор пакета). Отображаемое имя нужно списку.

## Открыть URL

Любой URL, который система умеет открыть. Жест по умолчанию «Открыть GitHub» использует этот тип.

## Медиа

| Команда | Роль |
|---------|------|
| playPause | Воспроизведение / пауза |
| nextTrack / previousTrack | Переход |
| volumeUp / volumeDown / mute | Громкость |

## Окно

| Команда | Роль |
|---------|------|
| close | Закрыть окно |
| minimize | Свернуть |
| zoom | Размер, выбранный приложением |
| maximize | Развернуть окно |
| fullscreen | Полный экран |
| hide | Скрыть приложение |
| center | Окно по центру |

Действия с окнами используют точное окно, зафиксированное в начале жеста, а не переднее окно в момент выполнения. Скрытие приложения относится к зафиксированному приложению. Если окно отсутствует, не поддерживает действие или нет разрешения Универсального доступа, показывается ошибка.

**Развернуть окно** заполняет доступную область экрана, на котором находится окно, с учётом строки меню и Dock. Повторный вызов сохраняет развёрнутый размер и не восстанавливает прежний. `zoom` использует размер, выбранный приложением, а `fullscreen` включает полноэкранный режим; развёрнутое окно остаётся на рабочем столе. Эта версия не выходит из полноэкранного режима перед разворачиванием — сначала выйдите вручную. Если положение или размер нельзя изменить либо окно не достигло требуемых границ, например из-за ограничений приложения, показывается ошибка.

Конфигурации и экспорт с разворачиванием окна в основном или втором действии используют формат **v5** и требуют совместимой версии. Для остальных действуют прежние правила v2/v3/v4.

## Shell

Выполняет локальную строку команды. Редактор подсвечивает синтаксис, чтобы длинные команды было легче проверить.

::: danger Риск
Shell имеет ваши пользовательские права на файлы и процессы. Вставляйте только понятные и доверенные команды.
:::

## AppleScript

Используйте **встроенный пресет** (сон, очистка Корзины, блокировка экрана, заставка, выход / перезагрузка / выключение, переключение тёмного режима, скрыть остальные, без звука / со звуком, панель принудительного завершения, снимок в буфер, открыть Загрузки) или переключитесь на **свой** скрипт. Управление другими приложениями может потребовать **Автоматизацию**. Редактор тоже подсвечивает синтаксис.

::: danger Риск
Тот же класс риска, что у Shell. Не запускайте недоверенные скрипты.
:::

## Как выбирать

| Цель | Предпочесть |
|------|--------|
| Системные / прикладные горячие клавиши | Сочетание |
| Запустить программу | Открыть приложение |
| Переход как по закладке | Открыть URL |
| Музыка и громкость | Медиа |
| Управление окнами | Окно |
| Сильная автоматизация | Shell / AppleScript (осторожно) |
