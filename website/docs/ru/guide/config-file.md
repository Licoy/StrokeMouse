# Файл конфигурации

Жесты и связанные настройки хранятся как **JSON**. Для выбранных жестов лучше **импорт / экспорт** в интерфейсе; для полной библиотеки копируйте локальный файл.

## Импорт / экспорт в интерфейсе

**Настройки → Жесты**:

1. **Экспорт** — множественный выбор жестов → сохранить пакет JSON (то же поле версии, что у формата конфигурации)
2. **Импорт** — выбрать JSON; если содержимое уже есть, **пропустить дубликаты** или **принудительно импортировать** (принудительные дубликаты по умолчанию выключены)

Удобно делиться несколькими любимыми жестами или синхронизировать подмножество между машинами, не заменяя всю библиотеку.

## Путь полной библиотеки

```text
~/Library/Application Support/StrokeMouse/gestures.json
```

В настройках можно **Показать в Finder**.

## Советы

| Сценарий | Подход |
|----------|----------|
| Поделиться / синхронизировать часть жестов | **Настройки → Жесты → Экспорт / Импорт** |
| Полная резервная копия | Скопировать папку `StrokeMouse` или только `gestures.json` |
| Улучшение прокрутки | Остаётся на этом Mac. Его нет в `gestures.json` и в резервной синхронизации; на новом Mac задайте снова в **Настройки → Прокрутка** |
| Новая машина | Установить + выдать доступ, затем импортировать пакет **или** заменить `gestures.json` и перезапустить |
| Ручное редактирование | Держать корректный JSON; предпочитать обратно совместимые необязательные поля |
| Повреждение | Удалить файл, чтобы заново создать значения по умолчанию (свои данные пропадут) |

::: warning
Приложение может перезаписать файл во время работы. Выйдите из приложения (или избегайте одновременной записи), прежде чем перезаписывать файл полной библиотеки.
:::

## Что внутри

В каждом профиле обычно есть:

- id, имя, включён
- **триггер** (правая / средняя / боковая…)
- **шаблон** (точки свободной траектории; старые списки направлений всё ещё декодируются)
- **действие** (сочетание, приложение, URL, медиа, окно, оболочка, AppleScript…)
- **область** (глобально или bundle id)
- заметки

Точные поля следуют моделям `Codable` приложения; после обновления файлы по возможности должны читаться. Импорт переносит старые списки направлений в free-path.

## Интерфейс и JSON

Для повседневного редактирования и пакетов используйте **Настройки → Жесты**. JSON полной библиотеки нужен для:

- полных резервных копий и переноса на другую машину
- хранения личных конфигураций в git (уберите приватные скрипты)
- восстановления повреждённых файлов

## Конфиденциальность

В Shell / AppleScript могут быть пути или токены. Замаскируйте их перед тем, как делиться пакетами экспорта или файлами конфигурации.
