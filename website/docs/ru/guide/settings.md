# Настройки и строка меню

## Строка меню

Повседневное управление:

- **Запуск / остановка жестов**
- **Пауза / возобновление прокрутки** — появляется, когда включена хотя бы одна функция прокрутки, и не зависит от паузы жестов
- **Открыть настройки**
- **Цвет состояния** — норма; **жёлтый**, когда жесты на паузе; **красный**, когда нет Универсального доступа
- **Выход**

По желанию запуск при входе, скрытый значок Dock и **скрытый значок в строке меню**. Если значок в строке меню скрыт, щёлкните StrokeMouse в Dock или перезапустите приложение, чтобы открыть настройки; если скрыт и Dock, перезапустите приложение. В основных настройках можно вернуть значок строки меню и **выйти из приложения**.

Скрытие и Dock, и строки меню требует подтверждения, чтобы не потерять все видимые точки входа.

## Разделы настроек

| Раздел | Содержание |
|---------|---------|
| **Жесты** | Боковая панель (глобально / по приложениям) + список: поиск / фильтр / пакетные операции, импорт/экспорт, редактор |
| **Прокрутка** | Обращение по осям, сглаживание ступенчатого колеса, исключения по переднему приложению; только на этом Mac |
| **Основные** | Оформление, элемент входа, скрыть Dock / строку меню, выход |
| **Доступ** | Состояние Универсального доступа / Автоматизации, пошаговое разрешение, глубокие ссылки |
| **О программе** | Версия и сведения о продукте |

## Улучшение прокрутки {#scroll-enhancement}

**Настройки → Прокрутка** отдельно от жестов. Системная «Естественная прокрутка» по-прежнему один общий переключатель для мыши и трекпада. Здесь можно обратить ещё раз по устройству и оси и добавить инерцию ступенчатому колесу.

- **Главный переключатель** по умолчанию включён, обращение и сглаживание выключены. Пока не включена ни одна функция, наблюдатель прокрутки не ставится, и жесты не меняются
- **Обращение** разделяет колесо мыши и трекпад / Magic Mouse, у каждой пары есть вертикаль и горизонталь. Оно накладывается поверх «Естественной прокрутки». Обращение горизонтали трекпада может влиять на смахивание в браузере. Горизонталь при прокрутке с Shift следует вертикальной настройке
- **Плавная прокрутка** только для ступенчатого колеса, не для трекпада и не для высокоточного колеса без фазы жеста. Пресеты: мягко, стандарт, чутко. Если в «Дополнительно» сдвинуть скорость, длительность или ускорение, режим станет своим. Скорость и ускорение действуют только при включённом сглаживании. Удержание Command, Option, Control или Shift оставляет системную прокрутку
- **Исключённые приложения** смотрят на **переднее приложение**, а не на окно под указателем. Это игры, удалённые рабочие столы, виртуальные машины и приложения, которые читают только целые строки и при сглаживании прокручиваются слишком мало
- Пауза жестов не останавливает прокрутку, её можно проверить в открытых настройках. Когда включена хотя бы одна функция, в строке меню появляются «Приостановить / возобновить прокрутку». Значок строки меню по-прежнему показывает только состояние жестов
- Эти настройки остаются на этом Mac и не входят в экспорт жестов, `gestures.json` и резервную синхронизацию. Другая утилита прокрутки может обработать событие дважды

Наблюдателю прокрутки тоже нужен Универсальный доступ. Без него прокрутка остаётся системной, а **Настройки → Доступ** показывает её состояние отдельной строкой.

## Список жестов

- Левая панель группирует по **глобальным** и **приложениям с областью** (похоже на области системных сочетаний); **Создать** под приложением заранее заполняет эту область
- Имя, триггер, действие, **область (глобально или значки приложений)**, состояние включения
- **Поиск** по имени / действию / заметкам; фильтр **Все / Вкл / Выкл**; сортировка по столбцам
- Создать / править / удалить; **множественный выбор** для пакетного включения, выключения, удаления или экспорта
- **Импорт / экспорт** пакетов JSON: экспорт выбранного; при импорте пропустить дубликаты или принудительно импортировать (принудительные дубликаты по умолчанию выключены)
- Значения по умолчанию можно менять и удалять

## Редактор жестов

Типичные поля профиля:

1. **Имя** и заметки
2. **Триггер**
3. **Путь** — записать точки свободной траектории (или шаблоны по направлениям)
4. **Действие** — см. [Действия](./actions)
5. **Область** — глобально или добавить приложения по значку (поиск установленных / множественный выбор / обзор `.app`; хранится как bundle id)
6. **Включено**

Удерживайте триггер для записи; отпустите, чтобы закончить. Перезаписывайте, пока не устроит.

## Тема и язык

- Оформление: следовать системе или принудительно светлая / тёмная
- Тексты: английский, упрощённый китайский, традиционный китайский, корейский, японский, русский и французский (или язык системы)

## Первый запуск

При первом запуске может появиться короткая подсказка. Доступ и этот сайт остаются долгосрочной справкой.

## Резервная копия и обмен

- **Повседневно**: Настройки → Жесты → экспорт выбранного в JSON; импорт на другом Mac
- **Вся библиотека**: **Показать в Finder**, чтобы скопировать `gestures.json`. См. [Файл конфигурации](./config-file)
