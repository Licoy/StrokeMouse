# Жесты

Триггеры, выборка и правила сопоставления для надёжных пользовательских траекторий. Обращение и сглаживание прокрутки не входят в библиотеку жестов; см. [Настройки и строка меню](./settings#scroll-enhancement).

## Конвейер

```text
Удерживать триггер → выбрать путь → расстояние ≥ мин. штрих
     → отпустить → сопоставить среди кандидатов того же триггера → выполнить действие
```

1. **Триггер живёт в каждом профиле жеста** (по умолчанию правая кнопка)
2. Движок следит только за кнопками **включённых** жестов
3. При отпускании **область приложения** + передний `bundleIdentifier` фильтруют кандидатов

## Триггеры

Для каждого жеста:

| Триггер | Примечание |
|---------|--------|
| Правая | По умолчанию; короткий щелчок всё ещё открывает контекстное меню |
| Средняя | Щелчок колесом |
| Боковая назад / вперёд | Обычные кнопки большого пальца |

Левая кнопка и неконтролируемые кнопки **всегда** проходят дальше.

## Повтор короткого щелчка

После того как движок захватил нажатие триггера:

- Расстояние **ниже** `minStrokeDistance`: помеченный синтетический down/up **повторяет** обычный щелчок (меню работают)
- Как только начался настоящий штрих: группа down/drag/up **только для жеста**, не отдаётся переднему приложению

## Сопоставление свободной траектории

Основной распознаватель:

- Упорядоченная передискретизация по длине дуги
- Нормализация 1D / 2D
- Ограниченный поиск поворота **±12°**
- Оценка ≥ порога
- **Число сегментов / структура поворотов** как жёсткие ворота (не компенсируются оценкой)
- **Без** зеркала, реверса и near-miss запасных путей

Записывайте чистые штрихи в умеренном темпе; сложные формы перезаписывайте, пока не стабилизируются.

## Живой HUD

Пока триггер удерживается, текущий путь рисуется на экране, чтобы выровняться с шаблоном.

## Область приложения

| Область | Поведение |
|-------|----------|
| Глобально | Совпадение в любом переднем приложении |
| Конкретные приложения | Только когда переднее приложение в списке |

В редакторе выбирайте **установленные приложения по значку** (поиск, множественный выбор или обзор `.app`) — bundle id вручную вводить не нужно (сопоставление всё равно использует идентификаторы пакетов). Удобно для жестов только в браузере или только в IDE.

Столбец области в списке жестов показывает «Глобально» или компактный набор значков. В **Настройки → Жесты** левая панель просматривает глобальную группу и группы по приложениям; создание жеста под узлом заранее заполняет эту область.

## Вкл / выкл

Переключатель на каждый жест. Отключённые профили покидают набор наблюдения и пул сопоставления.
