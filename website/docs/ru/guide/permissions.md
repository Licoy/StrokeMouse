# Доступ

StrokeMouse нужен глобальный перехват мыши и необязательная автоматизация. Сбои видны в **строке меню** и **Настройки → Доступ**, а не молча.

## Обзор

| Доступ | Обязателен? | Назначение |
|------------|-----------|---------|
| **Универсальный доступ** | **Да** | Глобальная мышь и прокрутка (`CGEventTap`), вставка сочетаний, AX окон |
| **Автоматизация** | По желанию | AppleScript, управляющий другими приложениями |

## Универсальный доступ

### Зачем

Движок перехватывает последовательности мыши для **настроенных триггеров**. Если `AXIsProcessTrusted()` ложно, приложение **не должно** делать вид, что слушает. Когда включены обращение или сглаживание, улучшение прокрутки использует тот же доступ для слушателя только событий колеса. Без доступа прокрутка остаётся системной.

### Как включить

Предпочтительнее встроенный поток **пошагового разрешения** (первый запуск и **Настройки → Доступ**):

1. Нажмите **Пошаговое разрешение** — откроются **Конфиденциальность и безопасность → Универсальный доступ** и плавающая панель, которая следует за окном системных настроек
2. Перетащите **StrokeMouse** (сборки Debug — **StrokeMouse Dev**) с панели в список
3. Включите переключатель; приложение за несколько секунд обнаружит доверие и запустит движок жестов

Те же шаги можно выполнить вручную в системных настройках.

### Частые случаи

- **Обновления официальных сборок в приложении** (стабильная самоподписанная идентичность `StrokeMouse Release`): Универсальный доступ **обычно не нужно** выдавать заново
- **Переход со старых ad-hoc сборок, смена сертификата или новый путь установки**: разрешите **один раз**
- **Переключатель включён, но мёртвый**: выключите/включите или удалите и добавьте снова, затем перезапустите
- **Несколько копий**: разрешите тот двоичный файл, который реально запускаете

## Автоматизация

Нужна только для действий **AppleScript**, которые управляют другими приложениями. macOS спрашивает при первом использовании, отдельно для каждого целевого приложения.

## Безопасность

- Глобальные перехваты событий сильны — собирайте или скачивайте из доверенных источников
- **Shell / AppleScript** имеют те же права, что и пользователь; в интерфейсе остаются предупреждения — **добавляйте только доверенные скрипты**
- Инженерная политика: не выводить полные пользовательские скрипты в публичные журналы

## Самопроверка

Если ничего не работает:

1. Строка меню показывает проблемы доступа / движка?
2. Универсальный доступ включён для **этого** экземпляра приложения?
3. Жесты на паузе?
4. Используете кнопку мыши, которая **не** является настроенным триггером?
