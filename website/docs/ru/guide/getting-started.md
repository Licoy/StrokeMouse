# Быстрый старт

За несколько шагов запустите StrokeMouse и проверьте первый жест.

## Что нужно

- **macOS 14 Sonoma** или новее
- Любая мышь (триггер по умолчанию — **правая** кнопка; можно сменить для каждого жеста)
- Готовность выдать **Универсальный доступ (Accessibility)**

## Пять шагов

### 1. Запустите приложение

В строке меню появится значок StrokeMouse. Приложение живёт в строке меню; значок Dock можно скрыть в настройках.

### 2. Выдайте Универсальный доступ

Откройте **Настройки → Доступ**, перейдите в **Системные настройки → Конфиденциальность и безопасность → Универсальный доступ** и включите StrokeMouse.

::: tip
Без доверия движок **не** делает вид, что слушает события. Состояние видно в строке меню и на странице доступа — без тихих сбоев.
:::

### 3. Убедитесь, что жесты включены

В строке меню проверьте, что жесты активны; если на паузе — возобновите.

### 4. Откройте список жестов

**Настройки → Жесты** показывает значения по умолчанию (например, вверх → Mission Control). Свои жесты можно создать в любой момент.

### 5. Нарисуйте первую траекторию

1. Удерживайте **триггер** жеста (по умолчанию **правая** кнопка)
2. Проведите путь (например, вверх)
3. Отпустите

При совпадении выполняется привязанное действие. Пока триггер удерживается, на экране рисуется **живой HUD траектории**.

## Щелчок и жест

| Поведение | Результат |
|----------|--------|
| Нажали триггер, **почти не сдвинули**, отпустили | Короткий щелчок: синтетический щелчок воспроизводится — **контекстное меню работает** |
| Сдвинули дальше минимальной дистанции и отпустили | Режим жеста: последовательность down/drag/up только для жеста — контекстного меню **нет** |

Левая кнопка и неконтролируемые кнопки всегда проходят дальше.
