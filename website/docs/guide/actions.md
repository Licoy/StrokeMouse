# 动作类型

匹配成功后，`ActionExecutor` 按配置分发动作。以下为当前支持的类型。

## 一览

| 类型 | 说明 | 注意 |
|------|------|------|
| 无动作 | 仅用于测试匹配 | — |
| **快捷键** | 注入系统快捷键（含修饰键） | 依赖辅助功能 |
| **打开 App** | 从已安装应用中按图标选择并启动 | 底层按 bundle id |
| **打开 URL** | 用默认浏览器打开链接 | — |
| **媒体键** | 播放暂停、上下曲、音量、静音 | — |
| **窗口操作** | 关闭、最小化、缩放、最大化、全屏、隐藏、居中 | 依赖 AX |
| **Shell** | 执行 shell 命令（编辑器语法高亮） | **高权限** |
| **AppleScript** | 内置预设或自定义脚本（编辑器语法高亮） | **高权限**，可能需自动化权限 |

## 快捷键

快捷键只能通过录制设置，显示字段不可直接编辑。点击「录制」后，按实际顺序按下组合键，松开全部按键后完成；单独按 Esc 可取消录制。

支持包含普通键的组合（如 `⌘⌥Q`），也支持纯修饰键组合（如 `⌘⌥`）。录制结果按实际按下顺序显示；修饰键仅支持 Command、Option、Control 和 Shift。

录制快捷键后可点击「添加后续按键」，再录制最多 3 组按键；执行时在同一目标中依次按下，组间间隔约 50 毫秒，任一步失败即停止。例如 `⌘V` 后接 `↩` 可在聊天软件中粘贴并发送。旧版本只会执行第一组快捷键。

典型用途：Mission Control、切换桌面、App 内快捷键等。

## 打开应用

在动作选择器中从**已安装应用**按图标搜索、浏览 `.app` 选择即可，无需手写 bundle id（底层仍按 bundle identifier 启动）。名称用于列表展示。

## 打开 URL

任意 `https://` / `http://` 等系统可处理的 URL。默认手势中的「打开 GitHub」即此类型。

## 媒体键

| 命令 | 作用 |
|------|------|
| playPause | 播放 / 暂停 |
| nextTrack / previousTrack | 下一曲 / 上一曲 |
| volumeUp / volumeDown / mute | 音量与静音 |

## 窗口操作

| 命令 | 作用 |
|------|------|
| close | 关闭窗口 |
| minimize | 最小化 |
| zoom | 缩放至应用自定尺寸 |
| maximize | 最大化窗口 |
| fullscreen | 全屏 |
| hide | 隐藏应用 |
| center | 窗口居中 |

窗口动作使用手势开始时锁定的精确窗口，不会改为操作执行时的前台窗口；隐藏应用使用锁定的应用，目标窗口缺失、不支持操作或未获得辅助功能权限时会显示失败提示

**最大化窗口**铺满该窗口所在屏幕的可用区域，避开菜单栏和 Dock；再次触发保持最大化，不还原之前的大小，`zoom` 使用应用自定尺寸，`fullscreen` 进入全屏，而最大化仍留在当前桌面；此版本不会先退出全屏再最大化，请先手动退出全屏，窗口不支持调整位置或大小，或未达到所需位置和大小（例如可能受应用限制）时，会显示失败提示

主动作或第二动作包含最大化窗口的配置与导出使用 **v5**，需要支持该格式的版本；不含此动作的配置沿用现有 v2/v3/v4 规则

## Shell

执行本地 shell 命令字符串。编辑器提供语法高亮，便于核对长命令。

::: danger 风险
Shell 拥有与当前用户相当的文件系统与进程权限。恶意或误写命令可造成数据损失。请只粘贴你理解且信任的命令。
:::

## AppleScript

可选用**内置预设**（如睡眠、清空废纸篓、锁屏、屏保、注销 / 重启 / 关机、切换深色模式、隐藏其他窗口、静音 / 取消静音、强制退出面板、截图到剪贴板、打开下载文件夹），或切换为**自定义**脚本。控制其他 App 时，系统可能要求 **自动化** 权限。编辑器同样支持语法高亮。

::: danger 风险
与 Shell 类似，具有自动化与脚本执行能力。勿运行来源不明的脚本。
:::

## 选择建议

| 目标 | 推荐动作 |
|------|----------|
| 系统 / App 快捷键 | 快捷键 |
| 启动某软件 | 打开 App |
| 网页书签式跳转 | 打开 URL |
| 音乐与音量 | 媒体键 |
| 窗口管理 | 窗口操作 |
| 高度自定义 | Shell / AppleScript（慎用） |

配置持久化见 [配置文件](./config-file)。
