# 手势系统

理解触发键、轨迹采样与匹配规则，才能稳定自定义手势。滚动反向与平滑不在手势库里，见 [设置与菜单栏](./settings#scroll-enhancement)。

## 核心流程

```text
按住触发键 → 采样路径 → 位移 ≥ 最小滑动距离
       → 松开 → 在「同触发键」的候选中匹配 → 执行动作
```

1. **触发键写在每条手势配置上**（默认右键）
2. 引擎只监听**已启用手势**用到的按键集合
3. 松开时结合 **App 作用域** 与前台 `bundleIdentifier` 过滤候选

## 触发键

每条手势可独立选择：

| 触发键 | 说明 |
|--------|------|
| 右键 | 默认；短按仍可出右键菜单 |
| 中键 | 滚轮按下 |
| 侧键后退 / 前进 | 常见鼠标侧键 |

未监控的按钮**始终放行**，不会被手势引擎劫持；左键默认同样放行，例外见下方 [第二动作](#第二动作)。

## 第二动作

鼠标绘制手势可在编辑器中开启 **第二动作**：按住触发键绘制时点击一次左键，松开后只执行第二动作，未点击左键时执行主动作。

- 只有目标应用可用的手势中存在第二动作时，按住触发键期间的左键按下与松开才会被成对吞掉，其余情况左键照常放行
- 识别仍在全部候选中进行，左键只决定执行哪个动作；匹配到的手势未设置第二动作时不执行任何动作并提示
- 点击左键但未画出有效轨迹时取消本次手势，不回放右键点击
- 触控板绘制与触控手势不支持第二动作，始终执行主动作

## 鼠标按键映射

在 **添加 → 鼠标按键** 中为侧键（后退 / 前进）或中键新建映射，单击该按键即执行动作，无需绘制。菜单内置「后退侧键 · 后退」（⌘[）与「前进侧键 · 前进」（⌘]）两个预设。

- 松开按键时执行；同一按键也用于鼠标绘制时，未达到 `minStrokeDistance` 按单击执行映射，超过则识别为绘制，一次按下不会同时触发两者
- 目标应用只有该按键的映射、没有绘制手势时，按住移动也按单击处理
- 可开启「需同时按住修饰键」并选择 Fn / Control / Option / Shift / Command 之一，仅精确按住该键时触发（如 ⌘ + 侧键后退）；未开启的映射在按住任何修饰键时都不触发，因此同一按键可同时配置无修饰键与带修饰键的映射；所选修饰键也用于触控板绘制时会先进入触控板绘制，映射不会触发
- 沿用全局 / 应用组 / 指定应用作用域，只取最具体的一层；同一层有多条映射视为冲突，不执行并提示
- 目标应用没有该按键的任何手势或映射时，按键原样放行，例如保留浏览器原生的后退 / 前进
- 右键不支持映射，以免吞掉右键菜单；映射执行成功时不弹匹配提示

## 短按回放

触发键的 down 由引擎接管后：

- 若拖动距离 **未达到** `minStrokeDistance`：用带标记的合成 down/up **回放**为普通点击，保证右键菜单等行为可用；目标应用有该按键的映射时改为执行映射
- 若已开始有效绘制：该组 down/drag/up **只用于手势**，不会同时交给前台 App

## 轨迹匹配（freePath）

当前主路径为**自由轨迹模板匹配**：

- 有序弧长重采样
- 1D / 2D 归一化
- **±12°** 有限旋转搜索
- 分数需 ≥ 配置阈值
- **显著段数 / 连续转角** 作为结构门控（不可被分数补偿）
- **不使用**镜像、逆序或 near-miss 兜底

录制时尽量画干净、速度适中；复杂花体可多录几次选最稳的一条。

## 实时 HUD

按住触发键拖动时，屏幕上会绘制当前轨迹，便于对齐模板方向与形状。

## App 作用域

| 作用域 | 行为 |
|--------|------|
| 全局 | 任意前台 App 都可匹配 |
| 指定 App | 仅当前台应用落在列表内时参与匹配 |

在编辑器中可从**已安装应用**按图标搜索、多选或浏览 `.app` 添加，无需手写 bundle id（底层仍按 bundle identifier 过滤）。适合「仅在浏览器里有效」或「仅开发工具里有效」的手势。

手势列表的作用域列会显示「全局」或已选 App 的图标摘要。**设置 → 手势** 左侧栏可按全局 / 各 App 浏览与管理；在某一节点下新建会预填对应作用域。

## 启用 / 禁用

每条手势可单独开关。禁用后不参与监听集合与匹配，无需删除配置。
