# FAQ

## 제스처가 전혀 반응하지 않나요?

순서대로 확인하세요:

1. **이** 앱 복사본의 **손쉬운 사용**(경로 변경, 인증서 교체, ad-hoc → 자체 서명 이전은 재승인 필요; 같은 공식 신원의 앱 내 업데이트는 보통 불필요)
2. 일시 정지 또는 권한 오류에 대한 메뉴 막대 상태
3. 제스처가 **사용**인지
4. 구성된 **트리거**를 누르고 있는지(기본값 오른쪽, 왼쪽 아님)
5. 궤적이 충분히 긴지(짧은 클릭은 일반 클릭으로 재생됨)

[권한](./permissions)과 [빠른 시작](./getting-started)을 보세요.

## 우클릭 메뉴가 사라졌나요?

짧은 우클릭(거의 드래그 없음)은 메뉴를 열어야 합니다. 최소 거리를 넘기면 이벤트는 제스처 전용입니다 — 예상된 동작입니다.

메뉴가 필요하면 가볍게 클릭하고, 제스처는 충분히 길게 그리세요. 또는 제스처를 **가운데 / 측면** 버튼에 두고 오른쪽 클릭은 시스템에 맡기세요.

## 잘못된 제스처이거나 오인식이 많나요?

- 비슷한 경로를 더 다르게 만드세요
- 같은 트리거의 쓰지 않는 후보를 끄세요
- 더 깨끗한 템플릿을 다시 녹음하세요
- 앱 범위로 좁히세요

## 너무 엄격하거나 너무 느슨한가요?

일치는 점수 임계값과 구조 게이트를 씁니다. 너무 엄격하면 템플릿에 더 가깝게 다시 녹음하고, 너무 느슨하면 템플릿 모양을 바꾸거나 비슷한 제스처를 줄이세요.

## 윈도우 동작이 실패하나요?

손쉬운 사용을 확인하세요. 일부 앱은 AX 트리가 약합니다 — 동등한 단축키 동작을 시도하세요.

## Shell / AppleScript가 조용한가요?

- 명령 / 스크립트가 터미널 / 스크립트 편집기에서 혼자 동작하나요?
- 다른 앱을 제어할 때 **자동화**가 허용되었나요?
- 창 뒤에 시스템 프롬프트가 숨어 있나요?

## 메뉴 막대 아이콘을 숨겼나요?

Dock에서 StrokeMouse를 클릭하거나(Dock 아이콘이 아직 보이면) 앱을 다시 실행하면 설정이 열립니다. **설정 → 일반**에서 메뉴 막대 아이콘을 다시 보이거나 종료할 수 있습니다. Dock과 메뉴 막대 아이콘을 모두 숨겼다면 앱을 다시 실행해 설정에 들어갑니다.

## 로그인 시 시작되지 않나요?

**설정 → 일반**에서 켭니다. macOS가 꺼 두었다면 **시스템 설정 → 로그인 항목**도 확인하세요.

## 라이트 / 다크가 잘못된가요?

일반에서 모양을 강제하거나 「시스템 따르기」로 되돌리세요.

## 구성이 사라졌나요?

`~/Library/Application Support/StrokeMouse/gestures.json`을 확인하세요. 앱을 종료한 뒤 백업에서 복원하세요. 내보낸 JSON 패키지만 있으면 **설정 → 제스처 → 가져오기**를 쓰세요. [구성 파일](./config-file)을 보세요.

## 어떤 마우스가 필요한가요?

쓸 수 있는 트리거 버튼이 있는 마우스면 됩니다. 기본값은 **오른쪽** 버튼이며, 제스처마다 가운데 또는 측면 버튼으로 바꿀 수 있습니다. 트랙패드 클릭은 마우스 버튼으로 동작할 수 있습니다. 여러 손가락 트랙패드 제스처는 이 제품의 주요 흐름이 아닙니다. 스크롤 향상은 특정 마우스가 필요 없고, 부드럽게는 일반 휠만 됩니다.

## 스크롤 방향이나 느낌이 다른가요?

- 반전은 시스템의 자연스러운 스크롤 위에 겹칩니다. 마우스 휠과 트랙패드(Magic Mouse 포함)는 따로 설정합니다
- 부드럽게는 일반 휠만 적용됩니다. 트랙패드와 고정밀 휠은 반전만 하고 부드럽게 하지 않습니다
- Command, Option, Control, Shift를 누르고 있으면 부드럽게 하지 않습니다
- 제외 목록의 앱이 전면이면 아무 처리도 하지 않습니다. 제외는 전면 앱을 보며, 포인터 아래 창이 아닙니다
- 다른 스크롤 도구와 함께 쓰면 두 번 처리될 수 있습니다
- 스크롤 설정은 제스처 백업에 따라가지 않습니다. 다른 Mac에서는 **설정 → 스크롤**에서 다시 설정하세요

[설정과 메뉴 막대](./settings#scroll-enhancement)를 보세요.

## 제스처를 어떻게 백업 / 공유하나요?

- **일부 제스처**: 설정 → 제스처 → 다중 선택 → JSON **내보내기**; 다른 Mac에서 **가져오기**(중복은 건너뛰거나 강제 가져오기)
- **전체 라이브러리**: `~/Library/Application Support/StrokeMouse/` 또는 `gestures.json`만 복사; 설치 + 승인 후 복원

[구성 파일](./config-file)과 [설정과 메뉴 막대](./settings)를 보세요.
