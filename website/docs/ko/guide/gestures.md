# 제스처

안정적인 사용자 제스처를 위한 트리거, 샘플링, 일치 규칙입니다. 스크롤 반전과 부드럽게는 제스처 라이브러리에 없습니다. [설정과 메뉴 막대](./settings#scroll-enhancement)를 보세요.

## 파이프라인

```text
트리거 유지 → 경로 샘플 → 거리 ≥ 최소 스트로크
     → 손 뗌 → 같은 트리거 후보에서 일치 → 동작 실행
```

1. **트리거는 각 제스처 프로필에 있습니다**(기본값 오른쪽 버튼)
2. 엔진은 **활성화된** 제스처가 쓰는 버튼만 감시합니다
3. 손을 떼면 **앱 범위** + 전면 `bundleIdentifier`가 후보를 걸러 냅니다

## 트리거

제스처마다:

| 트리거 | 설명 |
|---------|--------|
| 오른쪽 | 기본값; 짧은 클릭은 컨텍스트 메뉴를 엽니다 |
| 가운데 | 휠 클릭 |
| 측면 뒤로 / 앞으로 | 일반적인 엄지 버튼 |

왼쪽 버튼과 감시하지 않는 버튼은 **항상** 통과합니다.

## 짧은 클릭 재생

엔진이 트리거-다운을 잡은 뒤:

- 거리가 `minStrokeDistance` **미만**: 표시된 합성 down/up이 일반 클릭을 **재생**합니다(메뉴가 동작)
- 실제 스트로크가 시작되면: down/drag/up 그룹은 **제스처 전용**이며 전면 앱으로 전달되지 않습니다

## 자유 경로 일치

기본 인식기:

- 순서 있는 호 길이 재샘플
- 1D / 2D 정규화
- **±12°** 제한 회전 검색
- 점수 ≥ 임계값
- **구간 수 / 꺾임 구조**를 점수로는 보상할 수 없는 하드 게이트로 사용
- 거울, 역순, near-miss 폴백 **없음**

중간 속도로 깨끗한 궤적을 녹음하세요. 복잡한 모양은 안정될 때까지 다시 녹음합니다.

## 실시간 HUD

트리거를 누르는 동안 현재 경로가 화면에 그려져 템플릿에 맞출 수 있습니다.

## 앱 범위

| 범위 | 동작 |
|-------|----------|
| 전역 | 어떤 전면 앱에서든 일치 |
| 특정 앱 | 전면 앱이 목록에 있을 때만 |

편집기에서 **설치된 앱을 아이콘으로** 고릅니다(검색, 다중 선택, `.app` 찾아보기). bundle id를 손으로 칠 필요는 없습니다(일치는 내부적으로 bundle identifier를 씁니다). 브라우저 전용이나 IDE 전용 제스처에 씁니다.

제스처 목록 범위 열은 「전역」 또는 앱 아이콘 요약을 보여 줍니다. **설정 → 제스처**의 왼쪽 사이드바는 전역과 앱별 그룹을 탐색합니다. 노드 아래에서 만들면 해당 범위가 미리 채워집니다.

## 사용 / 사용 안 함

제스처마다 토글합니다. 끈 프로필은 감시 집합과 일치 풀에서 빠집니다.
