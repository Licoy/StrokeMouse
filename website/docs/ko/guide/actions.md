# 동작

일치에 성공하면 `ActionExecutor`가 구성된 동작을 디스패치합니다.

## 개요

| 유형 | 하는 일 | 참고 |
|------|----------------|-------|
| 없음 | 일치만 / 테스트 | — |
| **단축키** | 키 화음 주입 | 손쉬운 사용 필요 |
| **시스템** | Mission Control, 응용 프로그램 윈도우, 이전 / 다음 Space | 손쉬운 사용 필요; 시스템 단축키와 일치해야 함 |
| **앱 열기** | 설치된 앱을 아이콘으로 골라 실행 | bundle id로 저장 |
| **URL 열기** | 기본 브라우저 / 핸들러 | — |
| **미디어** | 재생/일시 정지, 트랙, 볼륨, 음소거 | — |
| **윈도우** | 닫기, 최소화, 확대/축소, 최대화, 전체 화면, 가리기, 가운데 | AX 필요 |
| **Shell** | 셸 명령 실행(구문 강조 편집기) | **높은 권한** |
| **AppleScript** | 내장 프리셋 또는 사용자 스크립트(구문 강조) | **높은 권한**; 자동화 필요할 수 있음 |

## 단축키

단축키는 녹음으로만 설정하며 표시 필드는 읽기 전용입니다. **녹음**을 클릭하고 의도한 순서로 키를 누른 뒤 모두 떼면 끝납니다. Esc만 누르면 취소됩니다.

일반 키가 있는 단축키(예: `⌘⌥Q`)와 수정 키만 있는 단축키(예: `⌘⌥`)를 모두 지원합니다. 결과는 누른 순서로 표시됩니다. 지원 수정 키는 Command, Option, Control, Shift, Fn/Globe입니다. Fn은 단독으로도, 다른 키와 조합해서도 쓸 수 있습니다(예: macOS 15 이상에서 윈도우를 좌우로 배치하는 `fn⌃⇧←`).

녹음을 시작하기 전에 모든 수정 키를 뗀 뒤, 재생할 순서대로 키를 누르세요. Fn은 실제로 눌러야 하며, 시스템 설정에서 Fn으로 바꾼 키(예: Caps Lock)도 쓸 수 있습니다. Caps Lock은 키를 뗀 뒤에도 켜진 상태로 남을 수 있습니다.

## 시스템

동작 유형에서 「시스템」을 선택하면 다음 명령을 실행할 수 있습니다.

| 명령 | 기본 단축키 | 대상 |
|------|------|------|
| Mission Control | ⌃↑ | 현재 데스크탑에서 동작하며 고정된 윈도우를 활성화하지 않음 |
| 응용 프로그램 윈도우 | ⌃↓ | 고정된 앱과 윈도우를 먼저 활성화 |
| 이전 Space | ⌃← | 현재 데스크탑에서 동작하며 고정된 윈도우를 활성화하지 않음 |
| 다음 Space | ⌃→ | 현재 데스크탑에서 동작하며 고정된 윈도우를 활성화하지 않음 |

시스템 명령은 시스템 설정 › 키보드 › 키보드 단축키 › Mission Control에 있는 해당 단축키를 보내 실행하며, 기본값은 macOS 기본값과 같습니다. 시스템에서 바꿨다면 편집기에서 다른 단축키를 녹음해 덮어쓰거나 「기본 단축키 복원」으로 되돌릴 수 있습니다. 편집기는 이 시스템 설정을 읽어 해당 시스템 단축키가 꺼져 있거나 여기 설정과 다르면 경고하고, 「시스템 단축키 사용」으로 시스템 설정을 그대로 가져올 수 있습니다. StrokeMouse는 시스템 설정을 변경하지 않습니다.

기본 단축키를 쓰는데 시스템 설정에서 그 단축키가 꺼져 있으면, 아무 일 없이 넘어가지 않고 실행 시 오류를 표시합니다.

이들은 트리거마다 한 번 실행되는 개별 명령으로, 네이티브 네 손가락 제스처처럼 손가락을 따라가는 연속 애니메이션은 없습니다. 터치 제스처의 네 손가락 위로 / 아래로 프리셋은 Mission Control과 응용 프로그램 윈도우 시스템 명령을 사용합니다.

시스템 명령이나 드래그 스크롤이 포함된 구성과 내보내기는 **v4** 형식을 사용하고, Fn 단축키만 포함하면 **v3**, 그 밖에는 **v2**를 유지합니다. 이전 버전에서는 v3/v4 파일을 읽을 수 없습니다.

## 앱 열기

동작 선택기에서 **설치된 앱**을 아이콘으로 고릅니다(검색 또는 `.app` 찾아보기). bundle id를 손으로 칠 필요는 없습니다(실행은 여전히 bundle identifier를 씁니다). 표시 이름은 목록 UI용입니다.

## URL 열기

시스템이 열 수 있는 모든 URL. 기본 「GitHub 열기」가 이 유형입니다.

## 미디어

| 명령 | 역할 |
|---------|------|
| playPause | 재생 / 일시 정지 |
| nextTrack / previousTrack | 건너뛰기 |
| volumeUp / volumeDown / mute | 볼륨 |

## 윈도우

| 명령 | 역할 |
|---------|------|
| close | 윈도우 닫기 |
| minimize | 최소화 |
| zoom | 앱이 정한 크기로 확대/축소 |
| maximize | 윈도우 최대화 |
| fullscreen | 전체 화면 |
| hide | 앱 가리기 |
| center | 윈도우 가운데 |

윈도우 동작은 실행 시점의 전면 윈도우 대신 제스처가 시작될 때 고정한 정확한 윈도우를 대상으로 합니다. 앱 가리기는 고정한 앱에 적용됩니다. 대상 윈도우가 없거나 동작을 지원하지 않거나 손쉬운 사용 권한이 없으면 실패 메시지가 표시됩니다.

**윈도우 최대화**는 해당 윈도우가 있는 화면에서 메뉴 막대와 Dock을 제외한 사용 가능 영역을 채웁니다. 반복 실행해도 최대화를 유지하며 이전 크기로 복원하지 않습니다. `zoom`은 앱이 정한 크기를 사용하고 `fullscreen`은 전체 화면으로 전환하지만, 최대화는 데스크탑에 남습니다. 이 버전은 전체 화면을 종료한 뒤 최대화하지 않으므로 먼저 직접 종료하세요. 위치나 크기를 변경할 수 없거나 앱 제한 등으로 필요한 위치와 크기에 도달하지 못하면 실패를 표시합니다.

기본 동작 또는 보조 동작에 윈도우 최대화가 포함된 구성과 내보내기는 **v5** 형식이며 호환 버전이 필요합니다. 그 외에는 기존 v2/v3/v4 규칙을 유지합니다.

## Shell

로컬 명령 문자열을 실행합니다. 편집기가 구문을 강조해 긴 명령을 검토하기 쉽습니다.

::: danger 위험
Shell은 파일과 프로세스에 대해 사용자 수준의 권한을 가집니다. 이해하고 신뢰하는 명령만 붙여 넣으세요.
:::

## AppleScript

**내장 프리셋**(잠자기, 휴지통 비우기, 화면 잠금, 화면 보호기, 로그아웃 / 재시동 / 시스템 종료, 다크 모드 전환, 다른 항목 가리기, 음소거 / 음소거 해제, 강제 종료 패널, 클립보드로 스크린샷, 다운로드 열기)을 쓰거나 **사용자 정의** 스크립트로 전환합니다. 다른 앱을 제어하면 **자동화**가 필요할 수 있습니다. 편집기도 구문을 강조합니다.

::: danger 위험
Shell과 같은 등급의 위험입니다. 신뢰하지 않는 스크립트는 실행하지 마세요.
:::
