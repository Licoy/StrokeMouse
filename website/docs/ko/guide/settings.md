# 설정과 메뉴 막대

## 메뉴 막대

일상 제어:

- **제스처 시작 / 중지**
- **스크롤 향상 일시 정지 / 다시 시작** — 스크롤 기능을 하나라도 켜면 나타나며, 제스처 일시 정지와는 별개입니다
- **설정 열기**
- **상태 색** — 정상; 제스처가 일시 정지되면 **노랑**; 손쉬운 사용이 없으면 **빨강**
- **종료**

선택적으로 로그인 시 시작, Dock 아이콘 숨기기, **메뉴 막대 아이콘 숨기기**. 메뉴 막대 아이콘을 숨기면 Dock에서 StrokeMouse를 클릭하거나 앱을 다시 실행해 설정을 엽니다. Dock도 숨겼다면 앱을 다시 실행하세요. 일반 설정에서 메뉴 막대 아이콘을 되돌리고 **앱을 종료**할 수 있습니다.

Dock과 메뉴 막대 아이콘을 모두 숨기면 확인이 필요해 보이는 입구를 모두 잃지 않습니다.

## 설정 구역

| 구역 | 내용 |
|---------|---------|
| **제스처** | 사이드바(전역 / 앱별) + 목록: 검색 / 필터 / 다중 선택 일괄 작업, 가져오기/내보내기, 편집기 |
| **스크롤** | 축별 반전, 일반 휠 부드럽게, 전면 앱 제외. 이 Mac에만 저장 |
| **일반** | 모양, 로그인 항목, Dock / 메뉴 막대 숨기기, 종료 |
| **권한** | 손쉬운 사용 / 자동화 상태, 안내 승인, 딥 링크 |
| **정보** | 버전과 제품 정보 |

## 스크롤 향상 {#scroll-enhancement}

**설정 → 스크롤**은 제스처와 분리된 휠 향상입니다. 시스템의 자연스러운 스크롤은 여전히 마우스와 트랙패드가 공유하는 스위치 하나입니다. 여기서는 기기와 축마다 한 번 더 반전하고, 일반 휠에 관성을 줄 수 있습니다.

- **마스터 스위치**는 기본으로 켜져 있고, 반전과 부드럽게는 꺼져 있습니다. 기능을 하나도 켜지 않으면 스크롤 감시를 설치하지 않으며 기존 제스처는 그대로입니다
- **반전**은 마우스 휠과 트랙패드 / Magic Mouse를 나누고, 각각 세로와 가로가 있습니다. 시스템 자연스러운 스크롤 위에 겹칩니다. 트랙패드 가로를 반전하면 브라우저 스와이프 이동에 영향을 줄 수 있습니다. Shift를 누른 스크롤의 가로는 세로 설정을 따릅니다
- **부드러운 스크롤**은 일반 휠만 처리합니다. 트랙패드와, 제스처 단계가 없는 고정밀 휠은 해당하지 않습니다. 프리셋은 부드럽게, 표준, 민감하게입니다. 고급에서 속도, 시간, 가속을 움직이면 사용자 지정이 됩니다. 속도와 가속은 부드럽게가 켜져 있을 때만 적용됩니다. Command, Option, Control, Shift를 누른 채로는 시스템 그대로입니다
- **제외한 앱**은 **전면 앱**을 봅니다. 포인터 아래 창이 아닙니다. 게임, 원격 데스크톱, 가상 머신, 그리고 정수 줄만 읽어 부드럽게 모드에서 너무 적게 움직이는 앱에 맞습니다
- 제스처를 일시 정지해도 스크롤은 멈추지 않습니다. 설정을 연 채로 시험할 수 있습니다. 기능을 하나라도 켜면 메뉴 막대에 「스크롤 향상 일시 정지 / 다시 시작」이 나타납니다. 메뉴 막대 아이콘은 여전히 제스처 상태만 나타냅니다
- 이 설정은 이 Mac에만 남고, 제스처 내보내기, `gestures.json`, 백업 동기화에는 들어가지 않습니다. 다른 스크롤 도구와 함께 쓰면 이벤트가 두 번 처리될 수 있습니다

스크롤 감시에도 손쉬운 사용이 필요합니다. 권한이 없으면 스크롤은 시스템 그대로이고, **설정 → 권한**에 스크롤 상태가 따로 표시됩니다.

## 제스처 목록

- 왼쪽 사이드바는 **전역**과 **범위가 지정된 앱**으로 묶습니다(시스템 단축키 범위와 비슷). 앱 아래에서 **새로 만들기**하면 해당 범위가 미리 채워집니다
- 이름, 트리거, 동작, **범위(전역 또는 앱 아이콘)**, 사용 상태
- 이름 / 동작 / 메모로 **검색**; **전체 / 사용 / 사용 안 함** 필터; 열 정렬
- 만들기 / 편집 / 삭제; **다중 선택**으로 일괄 사용, 사용 안 함, 삭제, 내보내기
- **가져오기 / 내보내기** JSON 패키지: 선택을 내보냅니다. 가져올 때 중복은 건너뛰거나 강제 가져오기(강제 가져온 중복은 기본적으로 꺼짐)
- 기본값은 수정·삭제할 수 있습니다

## 제스처 편집기

프로필의 일반적인 필드:

1. **이름**과 메모
2. **트리거**
3. **경로** — 자유 경로 점을 녹음(또는 방향 기반 템플릿)
4. **동작** — [동작](./actions) 참고
5. **범위** — 전역, 또는 아이콘으로 앱 추가(설치된 앱 검색 / 다중 선택 / `.app` 찾아보기; bundle id로 저장)
6. **사용**

트리거를 누른 채 녹음하고 손을 떼면 끝납니다. 마음에 들 때까지 다시 녹음하세요.

## 테마와 언어

- 모양: 시스템 따르기 또는 라이트 / 다크 강제
- 문구: 영어, 중국어 간체, 중국어 번체, 한국어, 일본어, 러시아어, 프랑스어(또는 시스템 언어 따르기)

## 온보딩

첫 실행에 짧은 안내가 나올 수 있습니다. 권한과 이 사이트가 장기 참고 자료입니다.

## 백업과 공유

- **일상**: 설정 → 제스처 → 선택을 JSON으로 내보내기; 다른 Mac에서 가져오기
- **전체 라이브러리**: **Finder에서 보기**로 `gestures.json`을 복사. [구성 파일](./config-file) 참고
