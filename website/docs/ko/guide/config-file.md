# 구성 파일

제스처와 관련 환경설정은 **JSON**으로 유지됩니다. 선택한 제스처는 UI로 **가져오기 / 내보내기**하는 편이 좋습니다. 전체 라이브러리 백업은 로컬 파일을 복사하세요.

## UI 가져오기 / 내보내기

**설정 → 제스처**:

1. **내보내기** — 제스처를 다중 선택 → JSON 패키지 저장(구성 형식과 같은 버전 필드)
2. **가져오기** — JSON 파일을 고릅니다. 내용이 이미 있으면 **중복 건너뛰기** 또는 **강제 가져오기**(강제 가져온 중복은 기본적으로 꺼짐)

좋아하는 제스처 몇 개를 공유하거나, 전체 라이브러리를 바꾸지 않고 여러 기기에서 일부를 맞출 때 좋습니다.

## 전체 라이브러리 경로

```text
~/Library/Application Support/StrokeMouse/gestures.json
```

설정에서 **Finder에서 보기**를 할 수 있습니다.

## 팁

| 상황 | 방법 |
|----------|----------|
| 일부 제스처 공유 / 동기화 | **설정 → 제스처 → 내보내기 / 가져오기** |
| 전체 백업 | `StrokeMouse` 폴더 또는 `gestures.json`만 복사 |
| 스크롤 향상 | 이 Mac에만 남습니다. `gestures.json`이나 백업 동기화에는 없습니다. 다른 Mac에서는 **설정 → 스크롤**에서 다시 설정하세요 |
| 새 기기 | 설치 + 승인 후 패키지를 가져오거나 `gestures.json`을 교체하고 다시 실행 |
| 손 편집 | 유효한 JSON 유지; 하위 호환 선택 필드 선호 |
| 손상 | 파일을 지워 기본값을 다시 만듦(사용자 데이터 손실) |

::: warning
앱이 실행 중이면 파일을 다시 쓸 수 있습니다. 전체 라이브러리 파일을 덮어쓰기 전에 앱을 종료하세요.
:::

## 안에 있는 것

각 프로필은 보통 다음을 가집니다:

- id, 이름, 사용 여부
- **트리거**(오른쪽 / 가운데 / 측면…)
- **패턴**(자유 경로 점; 예전 방향 목록도 디코드됨)
- **동작**(단축키, 앱, URL, 미디어, 윈도우, 셸, AppleScript…)
- **범위**(전역 또는 bundle id)
- 메모

정확한 필드는 앱의 `Codable` 모델을 따릅니다. 업그레이드 후에도 가능한 한 읽을 수 있어야 합니다. 가져오기는 예전 방향 목록을 free-path로 옮깁니다.

## UI와 JSON

일상 편집과 패키지 가져오기/내보내기는 **설정 → 제스처**를 쓰세요. 전체 라이브러리 JSON은 다음에 씁니다:

- 완전한 백업과 기기 이전
- git에 개인 구성 저장(비공개 스크립트 제거)
- 깨진 파일 복구

## 개인정보

Shell / AppleScript에 경로나 토큰이 있을 수 있습니다. 내보내기 패키지나 구성 파일을 공유하기 전에 가리세요.
