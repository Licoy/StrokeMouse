# 권한

StrokeMouse는 전역 마우스 감시와 선택적 자동화가 필요합니다. 실패는 **메뉴 막대**와 **설정 → 권한**에 보이며 조용히 넘어가지 않습니다.

## 개요

| 권한 | 필수? | 용도 |
|------|-----------|---------|
| **손쉬운 사용** | **예** | 전역 마우스와 스크롤(`CGEventTap`), 단축키 주입, 윈도우 AX |
| **자동화** | 선택 | 다른 앱을 제어하는 AppleScript |

## 손쉬운 사용

### 이유

엔진은 **구성된 트리거**의 마우스 시퀀스를 가로챕니다. `AXIsProcessTrusted()`가 거짓이면 앱은 감시 중인 척하면 **안 됩니다**. 스크롤 향상은 반전이나 부드럽게를 켠 뒤 같은 권한으로 휠 이벤트만 감시합니다. 권한이 없으면 스크롤은 시스템 그대로입니다.

### 켜는 방법

앱 안 **안내 승인** 흐름을 권장합니다(첫 실행 온보딩과 **설정 → 권한**):

1. **안내 승인**을 클릭합니다 — **개인정보 보호 및 보안 → 손쉬운 사용**과 시스템 설정 창을 따라다니는 플로팅 패널이 열립니다
2. 패널에서 **StrokeMouse**(Debug 빌드는 **StrokeMouse Dev**)를 목록으로 드래그합니다
3. 스위치를 켭니다. 앱이 수초 안에 신뢰를 감지하고 제스처 엔진을 시작합니다

시스템 설정에서 같은 단계를 직접 완료할 수도 있습니다.

### 흔한 경우

- **공식 빌드의 앱 내 업데이트**(고정 `StrokeMouse Release` 자체 서명): 손쉬운 사용을 **다시 줄 필요는 보통 없음**
- **예전 ad-hoc 빌드에서 이전, 서명 인증서 교체, 새 설치 경로**: **한 번** 다시 승인
- **스위치는 켜져 있는데 동작하지 않음**: 껐다 켜거나 항목을 지우고 다시 추가한 뒤 재실행
- **복사본이 여러 개**: 실제로 실행하는 바이너리를 승인

## 자동화

다른 앱을 제어하는 **AppleScript** 동작에만 필요합니다. macOS는 대상 앱마다 처음 사용할 때 묻습니다.

## 안전

- 전역 이벤트 탭은 강력합니다 — 신뢰하는 출처에서 빌드하거나 받으세요
- **Shell / AppleScript**는 사용자와 같은 권한을 가집니다. UI에 위험 경고가 남아 있습니다 — **신뢰하는 스크립트만 추가**하세요
- 공학 정책: 사용자 스크립트 전문을 공개 로그에 남기지 않습니다
