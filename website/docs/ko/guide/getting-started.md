# 빠른 시작

몇 단계로 StrokeMouse를 실행하고 첫 제스처를 확인합니다.

## 준비물

- **macOS 14 Sonoma** 이상
- 아무 마우스(기본 트리거는 **오른쪽** 버튼; 제스처마다 바꿀 수 있음)
- **손쉬운 사용(Accessibility)** 권한을 허용할 의사

## 다섯 단계

### 1. 앱 실행

메뉴 막대에 StrokeMouse 아이콘이 나타납니다. 앱은 메뉴 막대 중심이며, 설정에서 Dock 아이콘을 숨길 수 있습니다.

### 2. 손쉬운 사용 허용

**설정 → 권한**을 열고 **시스템 설정 → 개인정보 보호 및 보안 → 손쉬운 사용**으로 이동한 뒤 StrokeMouse를 켭니다.

::: tip
신뢰되지 않으면 엔진은 감시 중인 척하지 **않습니다**. 상태는 메뉴 막대와 권한 페이지에 보이며 조용히 실패하지 않습니다.
:::

### 3. 제스처가 켜져 있는지 확인

메뉴 막대에서 제스처가 활성인지 확인하고, 일시 정지되어 있으면 다시 켭니다.

### 4. 제스처 목록 열기

**설정 → 제스처**에 기본값(예: 위로 그리기 → Mission Control)이 있습니다. 언제든 직접 만들 수 있습니다.

### 5. 첫 궤적 그리기

1. 제스처 **트리거**를 누른 채 유지합니다(기본값 **오른쪽** 버튼)
2. 경로를 드래그합니다(예: 위쪽)
3. 손을 뗍니다

일치하면 바인딩된 동작이 실행됩니다. 트리거를 누르는 동안 **실시간 궤적 HUD**가 화면에 그려집니다.

## 클릭과 제스처

| 동작 | 결과 |
|------|------|
| 트리거를 누르고 **거의 움직이지 않은 채** 뗌 | 짧은 클릭: 합성 클릭이 재생되어 **컨텍스트 메뉴가 그대로 동작** |
| 최소 이동 거리를 넘긴 뒤 뗌 | 제스처 모드: down/drag/up 시퀀스는 제스처 전용이며 컨텍스트 메뉴는 **없음** |

왼쪽 버튼과 감시하지 않는 버튼은 항상 통과합니다.
