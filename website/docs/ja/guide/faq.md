# FAQ

## ジェスチャが全く反応しない？

順に確認してください:

1. **この** App コピーの**アクセシビリティ**（パス変更、証明書ローテーション、ad-hoc → 自己署名への移行は再承認が必要。同じ公式 ID のアプリ内アップデートは通常不要）
2. 一時停止や権限エラーのメニューバー状態
3. ジェスチャが**有効**か
4. 設定した**トリガー**を押しているか（デフォルトは右。左ではない）
5. 軌跡が十分長いか（短いクリックは通常クリックとして再生される）

[権限](./permissions) と [クイックスタート](./getting-started) を見てください。

## 右クリックメニューが出ない？

短い右クリック（ほとんどドラッグしない）ならメニューは開くはずです。最小距離を超えるとイベントはジェスチャ専用です — 想定どおりです。

メニューが必要なら軽くクリックし、ジェスチャは十分長く描いてください。ジェスチャを**中 / サイド**ボタンに割り当て、右クリックはシステムに残すこともできます。

## 違うジェスチャになる、誤認識が多い？

- 似た経路の差を広げる
- 同じトリガーの使わない候補をオフにする
- よりきれいなテンプレートを録り直す
- App 範囲で狭める

## 厳しすぎ / ゆるすぎ？

マッチングはスコアしきい値と構造ゲートを使います。厳しすぎるときはテンプレートに近づけて録り直し、ゆるすぎるときは形を変えるか似たジェスチャを減らします。

## ウインドウアクションが失敗する？

アクセシビリティを確認してください。一部の App は AX ツリーが弱いです。同等のショートカットアクションを試してください。

## Shell / AppleScript が動かない？

- コマンド / スクリプト単体はターミナル / スクリプトエディタで動きますか？
- 他の App を制御するとき**自動化**は許可されていますか？
- ウインドウの後ろにシステムダイアログが隠れていませんか？

## メニューバーアイコンを隠した？

Dock の StrokeMouse をクリックするか（Dock アイコンが見える場合）、アプリを再起動すると設定が開きます。**設定 → 一般**でメニューバーアイコンを再表示したり終了できます。Dock とメニューバーの両方を隠している場合は、アプリを再起動して設定に入ります。

## ログイン時に開かない？

**設定 → 一般**で有効にします。macOS がオフにしている場合は **システム設定 → ログイン項目** も確認してください。

## ライト / ダークが違う？

一般で外観を固定するか、「システムに従う」に戻してください。

## 設定が消えた？

`~/Library/Application Support/StrokeMouse/gestures.json` を確認してください。アプリを終了してからバックアップを戻します。書き出した JSON パッケージだけがある場合は **設定 → ジェスチャ → 読み込み** を使います。[設定ファイル](./config-file) を見てください。

## どのマウスが必要？

使えるトリガーボタンがあるマウスなら十分です。デフォルトは**右**ボタンで、ジェスチャごとに中またはサイドに変えられます。トラックパッドのクリックはマウスボタンとして使えることがあります。複数指のトラックパッドジェスチャはこの製品の主な流れではありません。スクロール強化に特定のマウスは不要ですが、滑らかにできるのは段付きホイールだけです。

## スクロールの方向や感触が違う？

- 反転はシステムの「ナチュラルスクロール」の上に重なります。マウスホイールとトラックパッド（Magic Mouse を含む）は別設定です
- スムーズ化は段付きホイールだけです。トラックパッドと高精度ホイールは反転のみで、滑らかにはしません
- Command、Option、Control、Shift を押しているあいだはスムーズ化しません
- 除外リストのアプリが最前面のときは何もしません。除外は最前面アプリを見て、ポインタ下のウインドウではありません
- 他のスクロールツールと同時に動かすと、2 回処理されることがあります
- スクロール設定はジェスチャのバックアップに入りません。別の Mac では **設定 → スクロール** で入れ直してください

[設定とメニューバー](./settings#scroll-enhancement) を見てください。

## ジェスチャのバックアップ / 共有は？

- **一部のジェスチャ**: 設定 → ジェスチャ → 複数選択 → JSON を**書き出し**。別の Mac で**読み込み**（重複はスキップまたは強制）
- **ライブラリ全体**: `~/Library/Application Support/StrokeMouse/` または `gestures.json` だけをコピー。インストール + 承認のあと復元

[設定ファイル](./config-file) と [設定とメニューバー](./settings) を見てください。
