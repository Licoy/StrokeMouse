# クイックスタート

少ない手順で StrokeMouse を動かし、最初のジェスチャを確認します。

## 必要なもの

- **macOS 14 Sonoma** 以降
- 任意のマウス（デフォルトのトリガーは**右**ボタン。ジェスチャごとに変更できます）
- **アクセシビリティ** を許可する意思

## 5 ステップ

### 1. アプリを起動

メニューバーに StrokeMouse のアイコンが出ます。アプリはメニューバー中心で、設定で Dock アイコンを隠せます。

### 2. アクセシビリティを許可

**設定 → 権限**を開き、**システム設定 → プライバシーとセキュリティ → アクセシビリティ**に移動して StrokeMouse をオンにします。

::: tip
信頼されていないとき、エンジンは監視しているふりを**しません**。状態はメニューバーと権限ページに見え、黙って失敗しません。
:::

### 3. ジェスチャが有効か確認

メニューバーでジェスチャが動作中か確認し、一時停止なら再開します。

### 4. ジェスチャ一覧を開く

**設定 → ジェスチャ**にデフォルト（例: 上方向 → Mission Control）があります。いつでも自分で作れます。

### 5. 最初の軌跡を描く

1. ジェスチャの**トリガー**を押したままにします（デフォルトは**右**ボタン）
2. 経路をドラッグします（例: 上方向）
3. 指を離します

一致すると、バインドしたアクションが実行されます。トリガーを押している間、画面に**リアルタイム軌跡 HUD** が描かれます。

## クリックとジェスチャ

| 操作 | 結果 |
|------|------|
| トリガーを押し、**ほとんど動かさず**離す | 短押し: 合成クリックが再生され、**コンテキストメニューは使える** |
| 最小移動距離を超えて離す | ジェスチャモード: down/drag/up はジェスチャ専用で、コンテキストメニューは**出ない** |

左ボタンと監視していないボタンは常に通過します。
