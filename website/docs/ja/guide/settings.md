# 設定とメニューバー

## メニューバー

日常の操作:

- **ジェスチャの開始 / 停止**
- **スクロール強化の一時停止 / 再開** — スクロール機能を 1 つでもオンにすると表示され、ジェスチャの一時停止とは独立しています
- **設定を開く**
- **状態の色** — 通常。ジェスチャ一時停止は**黄**。アクセシビリティ不足は**赤**
- **終了**

任意でログイン時に開く、Dock アイコンを隠す、**メニューバーアイコンを隠す**。メニューバーアイコンを隠したあとは、Dock の StrokeMouse をクリックするかアプリを再起動して設定を開きます。Dock も隠している場合はアプリを再起動します。一般設定でメニューバーアイコンを戻し、**アプリを終了**できます。

Dock とメニューバーの両方を隠すときは確認が入り、見える入口をすべて失わないようにします。

## 設定セクション

| セクション | 内容 |
|---------|---------|
| **ジェスチャ** | サイドバー（グローバル / App ごと）+ 一覧: 検索 / フィルタ / 複数選択の一括操作、読み込み/書き出し、エディタ |
| **スクロール** | 軸ごとの反転、段付きホイールのスムーズ化、最前面アプリの除外。この Mac だけに保存 |
| **一般** | 外観、ログイン項目、Dock / メニューバーを隠す、終了 |
| **権限** | アクセシビリティ / 自動化の状態、ガイド承認、ディープリンク |
| **情報** | バージョンと製品情報 |

## スクロール強化 {#scroll-enhancement}

**設定 → スクロール** はジェスチャとは別のホイール強化です。システムの「ナチュラルスクロール」は今までどおりマウスとトラックパッドで共有の 1 つのスイッチです。ここではデバイスと軸ごとにさらに反転でき、段付きホイールに慣性を付けられます。

- **マスタースイッチ**はデフォルトでオン、反転とスムーズ化はオフです。機能が 1 つもオンでないときはスクロール監視を入れず、既存のジェスチャはそのままです
- **反転**はマウスホイールと、トラックパッド / Magic Mouse を分け、それぞれ縦と横があります。システムの「ナチュラルスクロール」の上に重なります。トラックパッドの横を反転すると、ブラウザのスワイプ移動に影響することがあります。Shift を押したスクロールの横移動は縦の設定に従います
- **スムーズスクロール**は段付きホイールだけです。トラックパッドや、ジェスチャ位相のない高精度ホイールは対象外です。プリセットは「やわらか / 標準 / 敏速」。詳細で速度、時間、加速を動かすとカスタムになります。速度と加速はスムーズ化がオンのときだけ効きます。Command、Option、Control、Shift を押しているあいだはシステムのままです
- **除外するアプリ**は**最前面のアプリ**を見ます。ポインタ下のウインドウではありません。ゲーム、リモートデスクトップ、仮想マシン、整数行だけを読むためスムーズ化だと動きが小さくなるアプリ向けです
- ジェスチャを一時停止してもスクロールは止まりません。設定を開いたまま試せます。機能を 1 つでもオンにすると、メニューバーに「スクロール強化を一時停止 / 再開」が出ます。メニューバーアイコンは引き続きジェスチャの状態だけを表します
- この設定はこの Mac だけに残り、ジェスチャの書き出し、`gestures.json`、バックアップ同期には入りません。他のスクロールツールと同時に動かすと、イベントが 2 回処理されることがあります

スクロール監視にもアクセシビリティが必要です。未許可のときはスクロールはシステムのままになり、**設定 → 権限** にスクロール状態が単独で出ます。

## ジェスチャ一覧

- 左サイドバーは**グローバル**と**範囲付き App**でまとめます（システムのショートカット範囲に近い）。App の下で**新規**すると、その範囲が事前入力されます
- 名前、トリガー、アクション、**範囲（グローバルまたは App アイコン）**、有効状態
- 名前 / アクション / メモで**検索**。**すべて / 有効 / 無効**でフィルタ。列ソート
- 作成 / 編集 / 削除。**複数選択**で一括の有効化、無効化、削除、書き出し
- **読み込み / 書き出し** JSON パッケージ: 選択を書き出します。読み込み時、重複はスキップまたは強制読み込み（強制した重複はデフォルトでオフ）
- デフォルトは編集・削除できます

## ジェスチャエディタ

プロファイルの典型的な欄:

1. **名前**とメモ
2. **トリガー**
3. **経路** — 自由軌跡の点を記録（または方向テンプレート）
4. **アクション** — [アクション](./actions) を参照
5. **範囲** — グローバル、またはアイコンで App を追加（インストール済みを検索 / 複数選択 / `.app` を参照。bundle id として保存）
6. **有効**

トリガーを押したまま記録し、離すと完了です。納得するまで録り直してください。

## テーマと言語

- 外観: システムに従うか、ライト / ダークを固定
- 文言: 英語、簡体字中国語、繁体字中国語、韓国語、日本語、ロシア語、フランス語（またはシステム言語に従う）

## オンボーディング

初回起動で短い案内が出ることがあります。権限とこのサイトが長期の参照先です。

## バックアップと共有

- **日常**: 設定 → ジェスチャ → 選択を JSON として書き出し、別の Mac で読み込む
- **ライブラリ全体**: **Finder に表示**で `gestures.json` をコピー。[設定ファイル](./config-file) を参照
