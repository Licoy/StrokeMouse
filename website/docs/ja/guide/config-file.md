# 設定ファイル

ジェスチャと関連設定は **JSON** で残ります。選んだジェスチャは UI で**読み込み / 書き出し**するのがおすすめです。ライブラリ全体のバックアップはローカルファイルをコピーしてください。

## UI の読み込み / 書き出し

**設定 → ジェスチャ**:

1. **書き出し** — ジェスチャを複数選択 → JSON パッケージを保存（設定形式と同じバージョン欄）
2. **読み込み** — JSON ファイルを選ぶ。内容が既にある場合は**重複をスキップ**または**強制読み込み**（強制した重複はデフォルトでオフ）

お気に入りを数本共有したり、ライブラリ全体を置き換えずに複数マシンで一部を揃えるのに向きます。

## 全ライブラリのパス

```text
~/Library/Application Support/StrokeMouse/gestures.json
```

設定から **Finder に表示**できます。

## ヒント

| 場面 | やり方 |
|----------|----------|
| 一部のジェスチャを共有 / 同期 | **設定 → ジェスチャ → 書き出し / 読み込み** |
| 全体バックアップ | `StrokeMouse` フォルダ、または `gestures.json` だけをコピー |
| スクロール強化 | この Mac だけに残ります。`gestures.json` やバックアップ同期には入りません。別の Mac では **設定 → スクロール** で入れ直してください |
| 新しいマシン | インストール + 承認のあと、パッケージを読み込むか `gestures.json` を置き換えて再起動 |
| 手編集 | 正しい JSON を保つ。後方互換の任意フィールドを優先 |
| 破損 | ファイルを消してデフォルトを再生成（カスタムは失われる） |

::: warning
アプリ実行中はファイルを書き戻すことがあります。全ライブラリファイルを上書きする前にアプリを終了してください。
:::

## 中身

各プロファイルはだいたい次を持ちます:

- id、名前、有効
- **トリガー**（右 / 中 / サイド…）
- **パターン**（自由軌跡の点。古い方向リストもデコードされる）
- **アクション**（ショートカット、App、URL、メディア、ウインドウ、シェル、AppleScript…）
- **範囲**（グローバルまたは bundle id）
- メモ

正確なフィールドはアプリの `Codable` モデルに従います。アップグレード後もできるだけ読めるべきです。読み込み時、古い方向リストは free-path に移行されます。

## UI と JSON

日常の編集とパッケージの読み書きは **設定 → ジェスチャ** を使ってください。全ライブラリ JSON は次に向きます:

- 完全バックアップとマシン移行
- git に個人設定を置く（非公開スクリプトは除く）
- 壊れたファイルの修復

## プライバシー

Shell / AppleScript にはパスやトークンが含まれることがあります。書き出しパッケージや設定ファイルを共有する前に伏せてください。
