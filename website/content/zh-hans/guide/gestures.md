# 手势系统

理解触发键、轨迹采样与匹配规则，才能稳定自定义手势。滚动反向与平滑不在手势库里，见 [设置与菜单栏](./settings#scroll-enhancement)。

## 核心流程

```text
按住触发键 → 采样路径 → 位移 ≥ 最小滑动距离
       → 松开 → 在「同触发键」的候选中匹配 → 执行动作
```

1. **触发键写在每条手势配置上**（默认右键）
2. 引擎只监听**已启用手势**用到的按键集合
3. 松开时结合 **App 作用域** 与前台 `bundleIdentifier` 过滤候选

## 触发键

每条手势可独立选择：

| 触发键 | 说明 |
|--------|------|
| 右键 | 默认；短按仍可出右键菜单 |
| 中键 | 滚轮按下 |
| 侧键后退 / 前进 | 常见鼠标侧键 |

未监控的按钮**始终放行**，不会被手势引擎劫持；左键默认同样放行，例外见下方 [第二动作](#第二动作)。

## 第二动作

鼠标绘制手势可在编辑器中开启 **第二动作**：按住触发键绘制时点击一次左键，松开后只执行第二动作，未点击左键时执行主动作。

- 只有目标应用可用的手势中存在第二动作时，按住触发键期间的左键按下与松开才会被成对吞掉，其余情况左键照常放行
- 识别仍在全部候选中进行，左键只决定执行哪个动作；匹配到的手势未设置第二动作时不执行任何动作并提示
- 点击左键但未画出有效轨迹时取消本次手势，不回放右键点击
- 触控板绘制与触控手势不支持第二动作，始终执行主动作

## 鼠标按键映射

在 **添加 → 鼠标按键** 中为侧键（后退 / 前进）或中键新建映射，单击该按键即执行动作，无需绘制。菜单内置「后退侧键 · 后退」（⌘[）与「前进侧键 · 前进」（⌘]）两个预设。

- 松开按键时执行；同一按键也用于鼠标绘制时，未达到 `minStrokeDistance` 按单击执行映射，超过则识别为绘制，一次按下不会同时触发两者
- 目标应用只有该按键的映射、没有绘制手势时，按住移动也按单击处理
- 可开启「需同时按住修饰键」并选择 Fn / Control / Option / Shift / Command 之一，仅精确按住该键时触发（如 ⌘ + 侧键后退）；未开启的映射在按住任何修饰键时都不触发，因此同一按键可同时配置无修饰键与带修饰键的映射；所选修饰键也用于触控板绘制时会先进入触控板绘制，映射不会触发
- 沿用全局 / 应用组 / 指定应用作用域，只取最具体的一层；同一层有多条映射视为冲突，不执行并提示
- 目标应用没有该按键的任何手势或映射时，按键原样放行，例如保留浏览器原生的后退 / 前进
- 右键不支持映射，以免吞掉右键菜单；映射执行成功时不弹匹配提示

## 鼠标组合

在 **添加 → 鼠标组合** 中新建，无需录制轨迹，可复用全部动作、目标窗口与作用域。

| 触发方式 | 鼠标动作 | 执行时机 |
|--------|------|------|
| 按住右键 | 向上 / 向下滚动 | 每格滚轮执行一次，可连续触发 |
| 按住右键 | 点击左键 | 每次按住右键只在首次点击左键时执行 |
| 按住右键 | 拖动滚动 | 指针移动达到 10 点后横向 / 纵向滚动，松手即停 |
| 屏幕边缘（上 / 下 / 左 / 右） | 点击右键 | 在所选边缘按下并松开右键，且未开始绘制 |
| 屏幕边缘（上 / 下 / 左 / 右） | 向上 / 向下滚动 | 无需按住右键，最多每 100 毫秒执行一次 |

- 触发组合的右键按住或点击不会弹出右键菜单，也不再识别绘制；未触发组合时右键照常可用
- 「按住右键 + 点击左键」优先于第二动作；没有该组合时第二动作保持原有行为
- 未配置的滚轮方向和没有组合的应用照常滚动；组合使用的滚轮不会继续滚动页面
- 按住右键时，高精度滚轮的动作最短间隔 120 毫秒，避免一次滚动连续切换多个标签页；触控板、惯性滚动和其他滚动工具补发的平滑帧不会触发动作
- 边缘为每块显示器边界以内 3 个点，相邻显示器的接缝也算边缘；角落同时命中两条同级配置时视为冲突
- 作用域与冲突规则同鼠标按键映射：只取最具体的一层，同一层有多条视为冲突，不执行并提示；应用策略可单独停用全局「鼠标组合」

**拖动滚动**：在「按住右键」模式下选择「拖动滚动」，可调「灵敏度」（0.25–4 倍，步长 0.05）和「反向滚动」，默认内容跟随指针移动。按下右键后指针移动达到固定的 10 点才开始滚动，不跟随「最小滑动距离」；在此之前松开会回放普通右键点击，右键菜单仍可用，开始滚动后松开既不回放点击，也不识别绘制。滚动作用于开始滚动时指针下的内容，不激活任何窗口；应用作用域仍按按下右键时锁定的应用 / 窗口判断。松手立即停止，没有惯性、光标锁定或回中，因此屏幕边缘会限制可移动距离。拖动滚动不使用普通动作或第二动作，请保存后在编辑器外按住右键移动测试。

在最具体的同一级作用域（应用 > 应用组 > 全局）中，拖动滚动不能与右键绘制或另一条拖动滚动共存，运行时遇到此类冲突不执行任何操作，并显示专门的冲突提示。相同全局、应用列表相交或同一应用组的确定冲突在所有入口都会被阻止：编辑器保存、勾选或批量启用、「移动到」以及删除应用组时保留为全局手势会被拦下并列出冲突手势；「复制」会产生冲突时，副本以停用状态创建；导入时冲突手势以停用状态导入并列出；已处于冲突的启用手势（例如恢复备份后）会在手势列表中显示警告图标。已有手势不会被删除或自动停用，不同应用组之间的动态重叠仍由运行时判定。

## 短按回放

触发键的 down 由引擎接管后：

- 若拖动距离 **未达到** `minStrokeDistance`：用带标记的合成 down/up **回放**为普通点击，保证右键菜单等行为可用；目标应用有该按键的映射时改为执行映射；目标应用可用右键「拖动滚动」时，阈值改为固定的 10 点
- 若已开始有效绘制或拖动滚动：该组 down/drag/up **只用于手势**，不会同时交给前台 App

## 轨迹匹配（freePath）

当前主路径为**自由轨迹模板匹配**：

- 有序弧长重采样
- 1D / 2D 归一化
- **±12°** 有限旋转搜索
- 分数需 ≥ 配置阈值
- **显著段数 / 连续转角** 作为结构门控（不可被分数补偿）
- **不使用**镜像、逆序或 near-miss 兜底

录制时尽量画干净、速度适中；复杂花体可多录几次选最稳的一条。

## 实时 HUD

按住触发键拖动时，屏幕上会绘制当前轨迹，便于对齐模板方向与形状。

## App 作用域

| 作用域 | 行为 |
|--------|------|
| 全局 | 任意前台 App 都可匹配 |
| 指定 App | 仅当前台应用落在列表内时参与匹配 |

在编辑器中可从**已安装应用**按图标搜索、多选或浏览 `.app` 添加，无需手写 bundle id（底层仍按 bundle identifier 过滤）。适合「仅在浏览器里有效」或「仅开发工具里有效」的手势。

手势列表的作用域列会显示「全局」或已选 App 的图标摘要。**设置 → 手势** 左侧栏可按全局 / 各 App 浏览与管理；在某一节点下新建会预填对应作用域。

## 启用 / 禁用

每条手势可单独开关。禁用后不参与监听集合与匹配，无需删除配置。
