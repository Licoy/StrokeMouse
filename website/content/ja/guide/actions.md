# アクション

一致に成功すると、`ActionExecutor` が設定したアクションをディスパッチします。

## 概要

| 種類 | 内容 | 注意 |
|------|----------------|-------|
| なし | 一致のみ / テスト | — |
| **ショートカット** | キーコードを注入 | アクセシビリティが必要 |
| **システム** | Mission Control、アプリケーションウインドウ、前の／次の操作スペース | アクセシビリティが必要。システムのショートカットと一致させる |
| **App を開く** | インストール済み App をアイコンで選んで起動 | bundle id として保存 |
| **URL を開く** | デフォルトブラウザ / ハンドラ | — |
| **メディア** | 再生/一時停止、曲送り、音量、ミュート | — |
| **ウインドウ** | 閉じる、最小化、ズーム、最大化、フルスクリーン、隠す、中央 | AX が必要 |
| **Shell** | シェルコマンドを実行（シンタックスハイライト） | **高権限** |
| **AppleScript** | 組み込みプリセットまたはカスタム（シンタックスハイライト） | **高権限**。自動化が必要な場合あり |

## ショートカット

ショートカットは記録だけで設定し、表示欄は読み取り専用です。**記録**をクリックし、意図した順でキーを押し、すべて離すと完了です。Esc だけを押すとキャンセルします。

通常キー付き（例: `⌘⌥Q`）も、修飾キーだけ（例: `⌘⌥`）も使えます。結果は押した順で表示されます。対応する修飾キーは Command、Option、Control、Shift、Fn/地球儀です。Fn は単独でも他のキーと組み合わせても使えます（例: macOS 15 以降でウインドウを左右に並べる `fn⌃⇧←`）。

記録を始める前にすべての修飾キーを離し、再生したい順にキーを押してください。Fn は実際に押す必要があります（システム設定で Fn に割り当てたキー、たとえば Caps Lock でも可）。Caps Lock はキーを離したあともオンのままになることがあります。

## システム

アクションの種類で「システム」を選ぶと、次のコマンドを実行できます。

| コマンド | デフォルトのショートカット | 対象 |
|------|------|------|
| Mission Control | ⌃↑ | 現在のデスクトップで動作し、固定したウインドウは前面にしない |
| アプリケーションウインドウ | ⌃↓ | 固定したアプリとウインドウを先に前面にする |
| 前の操作スペース | ⌃← | 現在のデスクトップで動作し、固定したウインドウは前面にしない |
| 次の操作スペース | ⌃→ | 現在のデスクトップで動作し、固定したウインドウは前面にしない |

システムコマンドは「システム設定 › キーボード › キーボードショートカット › Mission Control」の対応するショートカットを送って実行し、デフォルトは macOS 標準と同じです。システム側で変更している場合は、エディタで別のショートカットを記録して上書きするか、「デフォルトのショートカットに戻す」で戻せます。エディタはこのシステム設定を読み取り、対応するショートカットがオフになっているか、ここでの設定と異なる場合に警告し、「システムのショートカットを使用」でシステム側の設定を取り込めます。StrokeMouse がシステム設定を変更することはありません。

デフォルトのショートカットを使っていて、システム設定でそのショートカットがオフの場合、実行しても何も起きないのではなくエラーを表示します。

これらはトリガーごとに 1 回実行される単発のコマンドで、ネイティブの 4 本指ジェスチャのように指に追従する連続アニメーションではありません。タッチジェスチャの 4 本指で上へ／下へのプリセットは、Mission Control とアプリケーションウインドウのシステムコマンドを使います。

システムコマンドまたはドラッグでスクロールを含む設定と書き出しは **v4** 形式、Fn ショートカットだけを含む場合は **v3**、それ以外は **v2** のままです。古いバージョンでは v3/v4 のファイルを読み込めません。

## App を開く

アクションピッカーで**インストール済み App** をアイコンから選びます（検索または `.app` を参照）。bundle id を手入力する必要はありません（起動は bundle identifier を使います）。表示名は一覧 UI 用です。

## URL を開く

システムが開ける任意の URL。デフォルトの「GitHub を開く」がこの種類です。

## メディア

| コマンド | 役割 |
|---------|------|
| playPause | 再生 / 一時停止 |
| nextTrack / previousTrack | スキップ |
| volumeUp / volumeDown / mute | 音量 |

## ウインドウ

| コマンド | 役割 |
|---------|------|
| close | ウインドウを閉じる |
| minimize | 最小化 |
| zoom | App が定めるサイズにズーム |
| maximize | ウインドウを最大化 |
| fullscreen | フルスクリーン |
| hide | App を隠す |
| center | ウインドウを中央へ |

ウインドウ操作は実行時の最前面ウインドウではなく、ジェスチャ開始時に固定した正確なウインドウを対象にします。「App を隠す」は固定した App が対象です。対象ウインドウがない場合、操作に非対応の場合、アクセシビリティ権限がない場合は失敗を表示します。

**ウインドウを最大化**は、そのウインドウがある画面のメニューバーと Dock を除く使用可能な領域いっぱいに広げます。再実行しても最大化を維持し、元のサイズには戻しません。`zoom` は App が定めるサイズを使用し、`fullscreen` はフルスクリーンに移行しますが、最大化はデスクトップに留まります。このバージョンはフルスクリーンを解除してから最大化することはないため、先に手動で解除してください。位置やサイズを変更できない場合や、App の制限などで必要な位置とサイズにならない場合は失敗を表示します。

主アクションまたは第2アクションに最大化を含む設定とエクスポートは **v5** 形式となり、対応バージョンが必要です。それ以外は既存の v2/v3/v4 ルールを維持します。

## Shell

ローカルのコマンド文字列を実行します。エディタが構文をハイライトするので、長いコマンドを確認しやすいです。

::: danger リスク
Shell はファイルとプロセスに対してユーザー相当の権限を持ちます。理解して信頼できるコマンドだけを貼ってください。
:::

## AppleScript

**組み込みプリセット**（スリープ、ゴミ箱を空にする、画面ロック、スクリーンセーバ、ログアウト / 再起動 / シャットダウン、ダークモード切替、ほかを隠す、ミュート / 解除、強制終了パネル、クリップボードへスクリーンショット、ダウンロードを開く）を使うか、**カスタム**スクリプトに切り替えます。他の App を制御すると**自動化**が必要になることがあります。エディタも構文をハイライトします。

::: danger リスク
Shell と同じクラスのリスクです。信頼できないスクリプトは実行しないでください。
:::

## 選び方

| 目的 | 優先 |
|------|--------|
| システム / App ホットキー | ショートカット |
| Mission Control / 操作スペースの切り替え | システム |
| ソフトを起動 | App を開く |
| ブックマークのような移動 | URL を開く |
| 音楽と音量 | メディア |
| ウインドウ管理 | ウインドウ |
| 強い自動化 | Shell / AppleScript（慎重に） |

永続化: [設定ファイル](./config-file)。
