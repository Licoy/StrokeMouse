Инструмент настройки жестов мыши и трекпада для macOS. Можно рисовать траекторию, удерживая кнопку мыши, рисовать на трекпаде с одной клавишей-модификатором или использовать экспериментальные мультитач-жесты. При совпадении выполняются сочетания клавиш, открытие приложений, операции с окнами, медиаклавиши, Shell / AppleScript и другое. Жесты действуют **глобально или для выбранного App**, конфигурации можно **импортировать и экспортировать**, всё работает локально и постоянно находится в строке меню.

## Возможности

- **Постоянно в строке меню**: включение и выключение жестов, открытие настроек, выход; цвет значка зависит от состояния (норма / пауза / нет доступа); можно **скрыть значок в строке меню** (если скрыт и Dock, будет повторное подтверждение; после скрытия откройте настройки через Dock или повторный запуск)
- **Библиотека жестов**: боковая панель по принципу **глобально / по приложениям** (при создании область подставляется заранее); поиск / фильтр / сортировка; пакетное включение, выключение и удаление; **импорт и экспорт JSON** (дубликаты можно пропустить или принудительно импортировать)
- **Рисование мышью**: у каждого жеста своя кнопка — правая, средняя или боковая; отслеживаются только кнопки включённых профилей
- **Рисование на трекпаде**: удерживайте ровно одну из клавиш Fn / Control / Option / Shift / Command (по умолчанию Fn) и двигайте указатель; дополнительная поддерживаемая клавиша отменяет текущее распознавание
- **Экспериментальные сенсорные жесты**: встроенный трекпад поддерживает 34 класса — касания и двойные касания тремя–пятью пальцами, свайпы в четыре стороны, а также щипок / разведение и вращение по / против часовой стрелки двумя–пятью пальцами
- **Главный переключатель сенсорных жестов**: канал сенсорных жестов можно выключить, не удаляя настроенные жесты; сбой закрытого бэкенда снижает только сенсорный канал, рисование мышью и на трекпаде продолжает работать
- **Улучшение прокрутки**: колесо мыши и трекпад / Magic Mouse можно обратить по вертикали и горизонтали отдельно, а для ступенчатого колеса есть плавная прокрутка (мягко / стандарт / чутко или свои скорость, длительность и ускорение). Исключения смотрят на переднее приложение. Настройки остаются на этом Mac и не входят в резервную синхронизацию. Другие утилиты прокрутки могут обработать событие дважды; приложения, читающие только целые строки (часть игр, ВМ, удалённых рабочих столов), лучше исключить
- **Отдельная цель у каждого жеста**: можно выбрать текущее переднее приложение или приложение под указателем в момент нажатия триггера; если есть обычное окно, оно тоже фиксируется, а проверка области и действия, зависящие от цели, всегда используют эту цель
- **Распознавание свободной траектории**: передискретизация по длине дуги + 1D/2D-нормализация + ограниченный поворот; структурные пороги по заметным изломам; глобальный порог совпадения настраивается в основных параметрах; при удержании триггера показывается живой HUD траектории
- **Область App**: глобально или добавление по значку из установленных приложений (поиск / обзор `.app`)
- **Разные действия**: сочетания клавиш, открытие / переключение App, URL, медиаклавиши, операции с окнами, Shell / AppleScript (подсветка синтаксиса; в AppleScript есть пресеты сна, блокировки экрана, очистки Корзины и свой скрипт)
- **Удобство**: интерфейс на английском, упрощённом китайском, традиционном китайском, корейском, японском, русском и французском (или язык системы), светлая / тёмная тема (системная или принудительная), запуск при входе, скрытие Dock / значка в строке меню, обновления Sparkle внутри приложения (при сбое — GitHub Releases)

## Системные требования

- macOS 14 Sonoma или новее
- Xcode 16+ (для сборок разработки)
- Рисованные жесты можно выполнять мышью или трекпадом; прямое мультитач в первую очередь рассчитано на встроенный трекпад Mac
- Внешний Magic Trackpad поддерживается по принципу best-effort и может зависеть от модели и версии системы

## Установка

### Homebrew (рекомендуется)

Установка из [поддерживаемого проектом Licoy Homebrew Tap](https://github.com/Licoy/homebrew-tap):

```bash
brew install --cask licoy/tap/strokemouse
```

StrokeMouse также обновляется из приложения. Чтобы Homebrew принудительно проверил и установил обновление:

```bash
brew upgrade --cask --greedy strokemouse
```

При удалении настройки по умолчанию сохраняются. Добавьте `--zap`, чтобы удалить и их:

```bash
brew uninstall --cask strokemouse
brew uninstall --cask --zap strokemouse
```

Можно скачать DMG нужной архитектуры на [официальной странице загрузок](https://strokemouse.com/ru/download). Текущие выпуски используют стабильную самоподписанную подпись и не нотаризованы Apple. Если Gatekeeper блокирует первый запуск, нажмите Control и щёлкните приложение, выберите «Открыть», либо в «Системных настройках → Конфиденциальность и безопасность» выберите «Всё равно открыть».

## Доступ

| Доступ | Назначение |
|--------|------------|
| **Универсальный доступ (Accessibility)** | Глобальный перехват мыши / модификаторов / прокрутки (`CGEventTap`), вставка сочетаний, AX-операции с окнами |
| **Автоматизация (Automation)** | По желанию; нужна, когда AppleScript управляет другими приложениями |

При первом запуске или в **Настройки → Доступ** можно использовать встроенное **пошаговое разрешение**: откройте системные настройки и перетащите StrokeMouse в список. Без доверия движок не делает вид, что слушает события.

### Экспериментальные сенсорные жесты

Сенсорные жесты загружают закрытый `MultitouchSupport` Apple во время выполнения через `dlopen` / `dlsym` и не связывают этот фреймворк статически. После обновления macOS он может перестать работать. Отсутствие фреймворка, символа, устройства или сбой запуска устройства показываются как отказ сенсорного канала; рисование мышью и на трекпаде продолжает работать, без имитации запасного пути и без тихих повторов.

StrokeMouse не перехватывает нативные события трекпада, поэтому системный жест может произойти вместе со связанным действием. Сырые траектории касаний не сохраняются и не журналируются. При первом сохранении, включении или импорте включённых профилей сенсорных жестов показывается подтверждение экспериментального риска. Затем главный переключатель может приостановить сенсорные жесты, не удаляя профили.

Поддерживаемые 34 класса сенсорных жестов:

| Семейство | Пальцы | Варианты | Число |
|-----------|--------|----------|-------|
| Касание | три / четыре / пять | одиночное, двойное | 6 |
| Свайп | три / четыре / пять | вверх, вниз, влево, вправо | 12 |
| Масштаб | два / три / четыре / пять | щипок, разведение | 8 |
| Вращение | два / три / четыре / пять | против часовой, по часовой | 8 |
| **Итого** |  |  | **34** |

Первая версия не поддерживает двухпальцевые касания / свайпы, комбинации модификаторов, идентификацию конкретных пальцев, непрерывно повторяемые действия и пользовательские пороги распознавания.

## Сборка и запуск

### Зависимости

```bash
brew install xcodegen
```

### Сгенерировать проект и открыть

```bash
./scripts/generate_project.sh
open StrokeMouse.xcodeproj
```

Или сразу **Run** в Xcode (Scheme: `StrokeMouse`).

### Сборка из командной строки (рекомендуется)

Стабильный путь `output/StrokeMouse.app` в репозитории снижает повторные запросы Универсального доступа.  
Debug отображается как **StrokeMouse Dev** (Bundle ID `com.strokemouse.app.dev`) и может быть разрешён отдельно от релизного **StrokeMouse**:

```bash
./scripts/build.sh           # Debug → output/StrokeMouse.app (Универсальный доступ: StrokeMouse Dev)
./scripts/build.sh --open    # открыть после сборки
./scripts/build.sh --release # Release (имя и Bundle ID как у релизного пакета)
```

### Релизная упаковка

ZIP, TAR.GZ и DMG по архитектурам, проверка подписи, entitlements и целостности артефактов (по умолчанию стабильная самоподпись **`StrokeMouse Release`**, чтобы доступ сохранялся после обновлений Sparkle):

```bash
# Первый раз локально: ./scripts/generate-codesign-cert.sh --import
SPARKLE_PUBLIC_KEY="..." ARCH=arm64 ./scripts/package-app.sh
SPARKLE_PUBLIC_KEY="..." ARCH=x86_64 ./scripts/package-app.sh
```

О релизе и секретах CI см. `RELEASING.md` / `certs/README.md`.

Версии: `./bump.sh -v x.y.z [-p]`. Перепоставить тот же тег и отправить: `./bump.sh -v x.y.z --force`.

### Тесты

```bash
xcodebuild -scheme StrokeMouse -configuration Debug test
```

## Использование

1. Запустите приложение — в строке меню появится значок мыши  
2. Выдайте **Универсальный доступ** и включите жесты из строки меню  
3. Откройте **Настройки → Жесты**, просмотрите стандартные жесты или создайте новые  
4. Выберите ввод: рисование с кнопкой мыши, рисование на трекпаде с одной клавишей-модификатором или настроенный сенсорный жест
5. При успешном совпадении выполняется связанное действие  

> **Короткое нажатие и жест**: нажатие и отпускание триггера временно захватывает движок. Если отпустить до «минимальной дистанции штриха», воспроизводится обычный щелчок, контекстное меню по-прежнему доступно. Когда рисование началось, перетаскивание двигает системный курсор и HUD, но переднее приложение не получает парные down/up — меню не открывается и не выбирается. Левая кнопка и кнопки, не назначенные триггером, всегда пропускаются.

> **Рисование на трекпаде**: наблюдение за модификаторами — listen-only и не поглощает клавиатурные события; короткий путь действие не выполняет. Траектория следует за системным указателем, его можно двигать трекпадом или мышью. StrokeMouse не подавляет обычный эффект модификатора в активном приложении.

> Сочетания клавиш сначала активируют зафиксированное приложение и выводят вперёд точное окно, если оно было захвачено, поэтому может смениться фокус или рабочий стол Spaces. В местах без обычного окна, например на рабочем столе Finder, по-прежнему работают сочетания и **Скрыть приложение**; закрытие, сворачивание, масштабирование, полный экран и центрирование требуют точного окна. Короткое нажатие цель не активирует.

Примеры жестов по умолчанию (по умолчанию правая кнопка; у каждого жеста может быть своя):

| Жест | Действие |
|------|----------|
| ↑ | Mission Control (⌃↑) |
| ↓ | Окна приложений (⌃↓) |
| ↓← | Свернуть окно |
| ↓→ | Закрыть окно |
| ↑→ | Открыть Safari |
| →← | Воспроизведение / пауза |
| ↑← | Открыть GitHub |

## Файл конфигурации

Путь:

```text
~/Library/Application Support/StrokeMouse/gestures.json
```

В повседневной работе выделяйте несколько пунктов в **Настройки → Жесты** и экспортируйте / импортируйте пакеты JSON. Для полной резервной копии скопируйте файл выше или правьте вручную (структура должна оставаться корректной). В настройках можно **показать в Finder**.

## Стек

- Swift / SwiftUI (macOS 14+)
- Лёгкий MVVM + Service
- `CGEventTap` для глобальных событий мыши / модификаторов
- Загрузка `MultitouchSupport` через `dlopen` / `dlsym` для экспериментальных сенсорных жестов (без статической линковки)
- Сохранение конфигурации в JSON
- [LaunchAtLogin-Modern](https://github.com/sindresorhus/LaunchAtLogin-Modern) для запуска при входе
- [Sparkle](https://github.com/sparkle-project/Sparkle) для подписанных обновлений внутри приложения
- XcodeGen для проекта Xcode
